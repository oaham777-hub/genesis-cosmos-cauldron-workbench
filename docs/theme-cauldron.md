# 主题规格：鼎（青铜）与宣纸（水墨）

工作台插件与可视化站共用一套 token 契约，各自出主题。第一版两个主题：

- `cauldron`（青铜·鼎）：默认，用于 DSH 工作台。
- `rice-paper`（宣纸·水墨）：用于独立可视化站（作品展示更安静）。

## 1. 视觉母题

**鼎 = 三级结构**：
- 双耳 = 顶部两条状态带（左：引擎/版本；右：数据新鲜度/连接态）
- 三足 = 三栏（造化鼎 / 乾坤鼎 / 组合）
- 鼎身纹样 = 饕餮纹分隔线、云雷纹底、回纹边框
- 炉火 = 运行/评估进行中的呼吸光

**中国风约束**：不用大红大金堆砌；只用"墨底 + 一点朱砂 + 一点赤金"；留白大于装饰。

## 4. 布局骨架

```
┌ 双耳：品牌/版本 ─────────────── 数据新鲜度/状态 ┐
│                                                │
│  三栏（三足）                                   │
│  ┌ 造化鼎 ┐ ┌ 乾坤鼎 ┐ ┌ 组合 ┐                │
│  │ 引擎状态│ │ 产品列表│ │ 占位 │                │
│  └────────┘ └────────┘ └──────┘                │
│                                                │
│  炉火状态条：最近导出时间 / 任务数 / 告警        │
└────────────────────────────────────────────────┘
```

- 侧边栏（DSH 右侧栏）：只放"三级树 + 快捷入口"，不放详情。
- 详情一律在主区，避免侧边栏变成第二个应用。

## 5. 特效（effects 注册表）

| id | 效果 | 触发 |
|---|---|---|
| `ember-glow` | 炉火呼吸：accent 径向渐变 + 2.4s 缓慢脉动 | 运行中/加载中 |
| `tea-smoke` | 香雾：模糊噪点层缓慢位移（8s） | 空态、首屏 |
| `bronze-patina` | 铜锈：低透明度噪点纹理叠加 | 卡片悬停 |
| `ink-wash` | 墨晕：hover 时 120ms 柔和扩散 | 按钮/列表项 |

统一接口（P0 定）：

```ts
export interface Effect {
  id: string;
  mount(el: HTMLElement, opts?: Record<string, unknown>): () => void;
}
export function registerEffect(effect: Effect): void;
```

未注册 id 自动降级为无特效；尊重 `prefers-reduced-motion: reduce`（全部动效关闭，仅保留静态渐变）。

- `agent-display`（PolyForm Noncommercial）：**只借氛围与配色思路，不搬代码、不搬 WebGL 场景**；若要商用需作者授权。

## 7. 验收

1. 两套主题切换不牵动布局（只换 token）。
2. 纹样全部为内联 SVG/CSS，无图片资源、无第三方依赖。
3. 减少动效模式下无动画。
4. 侧边栏宽度 ≤ 320px 时三栏降级为单列 + 折叠。
