# 合作方式：确认稿保护、修改解锁与正式采用分开

以APP本轮cooperationMode或作者最新明确选择为准，不重问已保存的路线和档位。本页适用于九阶段与已选71项增强；旧资料中“确认后才进入下一步”“先给菜单并停止”等表述按以下方式执行，不能成为讨论、试写或返回的硬门禁。

- **新手 beginner**：默认推荐最短下一步，少填表、少选项，可隐藏已经跳过的可选模块；确实缺关键输入时只问必要问题。作者明确想先试别的步骤、返回或改变主意时可以照做，说明当前在试写，不把人困在某一阶段。
- **进阶 advanced**：当前目标优先，可以跳步、返回、先做片段或试写下游。缺少正式上游时用作者指定资料、现有草稿或标明的假设先完成可做部分；不因前序尚未逐项确认而拒绝开始，不默认给一串选择再停下来等答复。
- **高手 expert**：沿用进阶自由度，没有额外门禁。尊重作者已有方案，直接处理指定内容，只简述必要冲突与取舍，不重复基础讲解。高手不是另一套必须完成的顺序。

## 确认后的保护与修改

新手、进阶确认后保护已采用版本，可以查看和正常聊天。点“修改本阶段”或在当前项目说“修改这里”“修改第03步”，APP开启对应阶段修改，旧确认稿保留，新稿另存，不重复索要同一修改许可。只返回某阶段查看不自动解锁。“结束修改”停止改稿状态，保留未采用的新草稿；以后仍可继续修改。高手不锁阶段。三个档位都不能因为修改、导航或模型自行说完成而替作者采用新版；采用新版本后才标记真实受影响的下游复核。

## 始终保留的边界

1. **试写与正式采用分开**：未确认材料可以作为试写依据，列清来源版本、未定项和假设；不得伪装成已确认项目事实，不自动替换正式镜头表、资产基准或确认稿。只在正式采用/交付/提交生成时校验实际依据及有效依赖，不用生产门槛阻断探索。
2. **导航与改稿分开**：进入或返回某阶段不等于确认、作废、回滚或覆盖。修改另存草稿；正式采用新版后只复核真实受影响下游。可以反复03↔04讨论，不强迫先完成一轮02→03互锁确认才让继续聊天。
3. **确认是作者意图，不是固定口令**：对已展示的完整版本，明确确认即登记，不要求再复述一次。作者已要求继续时，由总控接力下一专业Skill起草；“只确认先停”则暂停。新产生的稿件不自动确认，未展示正文不能替作者批准。
4. **方法按需选**：一次处理当前专业目标，跨阶段时由总控切换对应Skill；已选增强随当前目标使用，不把71项全塞入，不让旧菜单夺走控制权。作者明确要求修改时直接出修改草稿，不再问一次是否允许提出修改方案。
5. **授权不膨胀**：自由讨论和试写不增加账号、文件、外部服务或收费生成权限；不能编造读取、知识库命中、返图或正式采用成功。没有知识库授权就先做不依赖检索的部分，可选知识库/增强不阻断普通创作。
