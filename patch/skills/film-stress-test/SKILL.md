# 06 剧本压力测试 / Script Stress Test

## 合作方式与试写边界

继承总控的[合作方式](references/cooperationModes.md)和作者本轮目标。正式成果以确认依据为准；试写可使用明确标注的草稿、片段和假设，不把本Skill的生产输入要求当成讨论或返回的硬门禁。作者明确要求修改时直接出新草稿，不再重复询问是否开始；不自动确认、覆盖原件或执行收费生成。

涉及事实改稿、06 回退或长对话恢复时，执行总控的 [改稿联动与原件交接](references/revision-impact.md)：本集后文与已写后续集一起检查，完整新版与差异先保存，确认后才使真实依赖的下游过期；不靠一句局部替换或摘要代替原件。

进入本阶段（含直接调用）先执行 [九阶段菜单与保存位置](references/stage-entry-and-paths.md)：显示本阶段中英标题，按规则展示并保存当前阶段菜单选择；所有读写先解析实际项目路径。此入口不改变本阶段的专业边界。

读取 `references/source.md` 作为结构压力测试与病灶定位的完整方法来源。

## 定位与职责边界

1. 你是编剧链（01–05）与下游制作链（07 Lira、08 ACTING、09 CINEDANCE）之间的**结构闸门**。
2. 沿用项目已确认的时长、节奏和类型定位。06 只审故事与时长风险，不替导演预设快切、慢切或每镜秒数；节奏未定时在报告写待核实，不额外要求用户选择拍法。
3. **你只出诊断报告，绝不代笔改剧本。** 你的唯一正式产出是 `06-剧本压力测试/stress-test-report-vNNN.md`（单文件/云文件夹模式下对应 `06-压力测试报告-vNNN.md`）。你不改写 `01` 至 `05` 的任何正文，也不生成图像资产、表演节拍或视频提示词。
4. 每次审查必须扫描实际报告目录（新项目 `06-剧本压力测试/`，旧项目先解析原路径）已有报告取得下一个三位版本号（`v001 → v002 → v003`），**永远不覆盖上一份报告**——新旧报告并列对照，是判断上一轮回退是否真正修复病灶的唯一依据。
5. E“快速出片”路线只审已写成且已确认的首批剧本；可以对照全剧大纲判断承诺是否跑偏，但未写成剧本的集数不得算作已审。报告须列明本轮集数／场次范围；修订确认后只重审受影响范围，不能把全季未写的集说成通过压力测试。
6. 时长检查分清**已确认目标、文本估算、实际计时**。04/05标注的秒数及模型自己的时长表不是实测；应核对对白量、必要动作与停顿，写明估算依据和不确定性。没有表演或成片计时，不声称“精准达标”“偏差为零”或“100%可拍”。密集动作可提示制作风险，蒙太奇等只列为可选验证办法，不替导演规定必须快切；缺少实测本身不阻断写作、导航或保存，也不擅自改动作者目标时长。

## 权威输入与入口继承

1. **优先读取项目已确认文件**：
   - `00-项目管理/artifact-registry.md` 登记的最新已确认剧本（`05-正式剧本/screenplay-vNNN.md`）或用户明确指定的「作者锁定原剧本」；
   - `05-正式剧本/screenplay-timing-audit-vNNN.md`（若存在，作为场次时长与字数参考）及 `05` 版本卡中标注的「本批我最没把握的一场」；
   - 已确认的 `01 概念锚定`、`02 角色圣经`、`03 世界观`（如有）、`04 分场大纲`——用于核对主角目标弧，以及精准区分**「事件在 04 里压根没有（回 04）」**还是**「事件在 04 里有、但 05 没演出来（回 05）」**。
2. **审查入口四步门禁（不可跳过）**：
   - **第一步（先继承，不重问）**：上游已确认的**目标时长、形态、发布目标和审查方式**直接沿用；片长短不等于必须按短视频流量模型审。影展短片或作者表达型短片可用 A 的故事审查问题，不因小于五分钟自动转 B。初稿字数不能擅自改作者定位。
   - **第二步（补齐缺项）**：仅当外部剧本直接进入 `06` 且未确认时长或形态时，才按 `references/source.md` 的「档位判定与字数速查」给出预估（一律写「约 X 分钟」），并**停下来问一次时长与形态**（A 档还需确认故事总目标）。**沉默不等于确认时长**，用户未答前不得擅自开审。
   - **第三步（核对节奏依据）**：读取 04/05 已确认的节奏和停顿；没有记录时按文本证据审查，标明时长估算不确定。不得把快切设成默认，也不为审剧本多弹一次镜头拍法选择。
   - **第四步（开审）**：对用户只说“故事审查／留存审查”，不要把 01 的 B 电影节误读成 06 的内部 B 留存检查。电影节、长片及作者表达项目优先用故事审查，无论是否达到五分钟；作者确有短视频留存目标才叠加留存检查。对 B 艺术片的目标、反转与价值变化按作品形态适配，不以单一主人公目标或固定反转次数硬判失败。

## 判门例外与铁律

1. **先判方法适用性，不硬套模板扭曲作品**：遇到艺术片/散文电影/情绪流、主角是「不变」的见证者、无对白/极少对白作品、环形/多线/章节体/倒叙结构、系列片单集时，严格执行 `references/source.md` 末节「适用范围与边界」及总控判门例外表，按作品自身标准审视因果与推进，不拿三幕对抗或单线规则判死。
2. **严守 04 与 05 的病灶分界**：
   - 分场大纲（04）里**压根没有**该关键事件 → 病灶在 **04 分场大纲**（补法按代价从小到大：先试在现有场次加动作/反应 → 再试合并相邻场腾空间 → 最后才新增场次）。
   - 分场大纲（04）里**已有**该事件，但剧本正文（05）一句带过、情绪或反应没演出来 → 病灶在 **05 剧本深度融合**（就地补动作、对白、反应、停顿，禁止推回 04 白改全场号）。
   - 仅有外部剧本、无 04 分场可查且正文证据不足以断定属 04 还是 05 时 → 必须输出合格形态的 `病灶定位：04 或 05（待核实）`，并写全**「缺哪份证据、由哪道补（如 04 反推分场）、补完谁复核」**，严禁瞎猜起点直接改稿。
3. **允许「无需回退」**：当剧本各环均成立时，如实输出 `病灶定位：无需回退 ｜ 相对薄弱处：第 X 场（可选优化，不影响成立）`，严禁为了凑诊断硬把可选优化写成必改病灶。

## 输出登记与作者授权询问

执行 [编剧质量接力](references/story-development-quality.md) 的 06 小节：先记录冷读的观众理解，再用文本证据定位；诊断结论不能冒充改稿授权。

1. 报告完成后，先写入 `06-剧本压力测试/stress-test-report-vNNN.md`，并在聊天窗口完整展示。
2. 多处病灶跨不同道或不同场次时，末尾 `病灶定位` **必须分条编号列出**（禁止合并成一行），以便作者按条部分授权。
3. 在 `00-项目管理/artifact-registry.md` 与 `artifact-state.json` 中，将本报告状态登记为 **`已完成-结论`**（报告本身漏掉最弱一环或病灶道号时标 `已作废（不合格）` 并重审）。
4. 按结论决定下一动作，不把“报告已完成”变成新的统一确认门：
   - 没有未解决必改病灶（包括只有制作提醒或可选优化）：登记完成，关闭本次修订复审，在状态、路由和检查点一致记录“06 已完成，无需回退”。不再索要改稿授权，也不自动进入 07。
   - 旧病灶尚未解决：核对原授权的病灶、场次、修改边界；仍在授权内则沿用，不因报告换号重问。交对应阶段修改新草稿并等待确认，继续保留双计数器三次熔断。未授权或超出范围的部分才询问。
   - 出现新增必改病灶：只询问新范围；作者明确不改则保留原稿，不反复劝改。
   - 证据不足：列出需要核实的具体缺口，不伪装通过或发起无依据改稿。
5. 只有存在尚未授权的必改项时，显示适用的处置选项；选项绑定本次实际病灶，不能让作者重选已经完成的确认：

```text
【06 剧本压力测试报告 vNNN 已出】请选择下一步处置：
A. 按建议统一修改：列出完整步骤名称与原因（例如“回到04 分场大纲修改交接动机，再到05 正式剧本整合，最后回07 LIRA”）。只经过真正受影响的步骤。
B. 部分采纳（按病灶授权）：请告诉我只改哪几条编号、保留哪几场不动。
C. 保留原稿不改：记录诊断结论，保持当前剧本不变，结束本次审查；下一阶段另按作者明确指令处理。
```

未获作者明确授权前，任何上游阶段（01–05）一个字都不许改动。

新报告用 `register-conclusion --outcome passed|revision-required|uncertain` 保存结论；逐项用 `--blocking-issue` 和 `--resolved-issue` 记录病灶键，已授权修订可用 `--authorization-ref` 关联原授权。`passed` 不能同时含未解决必改项。旧报告没有这些字段时先核对正文，不把缺字段猜成通过。已完成且依据未变的报告不因“继续”重复生成。

作者选择和具体病灶授权必须保存到 `00-项目管理/project-status.md` 与 `routing.md`，不能只追加到自动生成的 `artifact-registry.md` 下方；登记表刷新会覆盖手写附注。06 报告本身是诊断结论，不作为剧情成果确认版；获授权后才由对应阶段写新草稿，作者采用对应完整新稿后由APP接力，不再次要求重述已授予的修改许可。新 05 剧本采用后默认按已选修订路线回到制作，不自动重跑06；作者明确选择复审时才审受影响范围，未复审不得冒称旧报告覆盖新版。并按成果依赖图先使旧剧本依赖的镜头、生成单元、提示词过期；全批共用剧本文件时，未修改场次须逐场核对后在新依据下复用，不能跳过核对。09 项目合作档位不重选。
