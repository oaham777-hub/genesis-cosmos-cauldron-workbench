# 编译闸检查表（L6 自检 · v2）

每条提示词交付前逐项自检并如实报告（S-32：检查结果只报不拦；用户决定是否修改）。下列 `FAIL` 字样仅是问题标签/严重度沿用，不构成交付拦截。本表是提示词交付前核验，不包含生成后审片。

## C0 平台能力硬门（S-33，先于以下自检）

- [ ] 本项目唯一目标平台已写入 `00_project/project-status.md`，精确到平台、模型/版本、提示词模式及资料覆盖的参考输入形态（如涉及）
- [ ] 唯一正式平台版本命中 `references/multi-model-adapters.md` 的可编译支持等级，并有对应专属适配依据
- [ ] 未通过能力门时停止正式平台编译，不得借其他目标的档案兜底

> 任一项未满足，**平台专属 L6 编译在此硬停**；平台无关上游工作可继续。该门是 S-33 的范围限制，不受 S-32“质量问题只报不拦”影响。用户明确要求通用草案时，须在标题与交付卡中标注“未验证通用草案，不可声称平台适配”。

- [ ] 无维度之间重复信息（身份只在 2，长相只在 2/6，曝光只在 3，镜头只在 4）
- [ ] 无维度越界（1 维不写风格，5 维不写本条目的，4 维不写曝光）
- [ ] 整体长度 ≤13 行（不含时间轴表）

## B 7 框架是否走通

- [ ] 整体判断：这一条的目的写得出
- [ ] 分镜时间轴：按秒闭合，合计＝本条时长
- [ ] 镜头语言：景别/运镜/构图/视点在**第 4 维**独立写清

- [ ] 光线色彩及质感：光影与色彩两维自洽
- [ ] 情绪曲线：本条情绪极性与上下条衔接

## C3 平台适配（v4 新增 · 按 H3）

**若目标平台为 MiniMax H3**（依据 `specs/h3-profile.md`）：

- [ ] 正文采用**七段语序**：主体 → 时序动作 → 场景环境 →【景别+运镜】→ 光影美术风格 → 音效描述 → 一致性约束
- [ ] **运镜绑定在动作后**（H3 允许并推荐），而非单独放在段末
- [ ] 使用**时间戳分镜**写法，且时刻与第 10 维时间轴一致、合计＝本条时长
- [ ] **音效与画面同步交代**（音与画成对出现），人声逐字台词仍标 `D1/D2`
- [ ] **无负面词堆砌**：第 12 维 B 段写「H3 无独立负向词框，约束已写入正文末尾（正向表述）」
- [ ] **末尾必有正向一致性约束段**（画面/色彩/人物/时长范围）
- [ ] 中文直写，**未夹带英文术语**，未把内部编号写进正文
- [ ] 违任一项 → 判 `[H3语序不合]` FAIL

> 若目标平台非 H3（如 Seedance），按该平台模块化结构改写，本段不适用，但第 12 维 A 段仍必须为正向表述。

## D 一致性与追溯（含 H8 新增项）

- [ ] 本条可追溯到镜号 + 摄影资产参数 + 光影资产方案 + 表演/情绪资产节拍
- [ ] **锚点复核（H8）**：本条用到的每个资产锁定项（疤、折痕、门缝宽度、字迹、锚点）均未被违反
- [ ] **本条终态（H6）**已写：位置 / 朝向 / 姿态 / 动作进度 / 道具状态 / 情绪强度，并已同步该场 `05_shots/<场次ID>/scene-registry.md`
- [ ] 资产职责不冲突（一条内两个素材抢同一职责 = 失败）
- [ ] 与全片「一只手」（质感/镜头性格/表演寄存器）一致；破格仅发生在转折条
- [ ] **跨层语义承接**：逐项核对所有适用上游 ID；每项映射到本镜 12 维或平台版的明确字段，或如实标为适配改写/不适用/缺失/待决定；不得以 12 维结构齐全代替语义覆盖
- [ ] **缺失与冲突清单**：列出未落入提示词的上游 ID、原因和用户需决定处；无缺口时明确写「本次承接核对未发现未映射项」并说明核对范围

## 判定

- 交付前逐项核对后，随提示词报告检查范围、未映射项与待决定处；**不得把结构完整写成语义完整的证明**。
