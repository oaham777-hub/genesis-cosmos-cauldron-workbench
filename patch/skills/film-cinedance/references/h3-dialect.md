# H3 方言操作篇（h3-dialect）

> 用途：把 `specs/h3-profile.md`（结构与禁令）之外**必须先定下来才能落笔**的操作项一次写清：**模式分派 → 素材上限 → 对白容量 → 时长同步**。
> 与现有文件的分工：`specs/h3-profile.md` 管**七段语序与禁令**（第二至五节）与**字段名对照**（第八节）；本文件管**模式 / 上限 / 对白 / 时长的执行判据**，不重复语序，不改写规范。
> 上位约束：`specs/prompt-framework.md`（12 维为唯一事实来源；H3 版本是**结构改写**，只改组织方式、不改信息）、`system-decisions.md` S-20 / S-21（H3 无独立负向词框）与硬门第 19、20 条。
> **来源与许可**：方法提炼自 `zenstory-ai/drama-skills`（**MIT**，`skills/short-drama-video-prompts/references/minimax-h3.md`）；**未复制其正文**，已按乾坤鼎口径（12 维、七段语序、`D*`/`T*` 编号、五出口）重写。

## 一、落笔前必过的四问

每条 H3 提示词在写正文之前，先回答：

| # | 问题 | 答错后果 |
|---|---|---|
| 1 | 本镜走**哪种模式**？（Base / 首帧 / 首尾帧 / full-reference） | 模式错 → 接口收到矛盾素材说明，**且不报错** |
| 2 | 本镜挂了**几张图 / 几段视频 / 几段音频**？是否超上限？ | 超上限 → 参考静默失效，正文里却写着它仍生效 |
| 3 | 本条对白的**完整发声需要多久**？镜长装得下吗？ | 装不下 → 赶词或静默截断 |
| 4 | 正文写的时长与生成设置的 `duration` **一致**吗？ | 不一致 → 秒数白写 |

四问对应下文第二至五节；任一未答清，不得进入正文撰写。

## 二、模式分派（由「输入参考图」的用途组合决定）

**模式不由「想不想用多模态」决定，由本镜槽位的用途组合决定。** 与上游 H3 官方口径一致。

| 本镜绑定的图 | 模式 | 正文结构 |
|---|---|---|
| 没有图，且已明确选择文生视频 | Base（文生） | 三段 |
| 只有一张「用途：起始帧」 | `first_frame` | 三段 |
| 一张「起始帧」+ 一张「结束帧」 | `first_last_frame` | 三段 |
| **其他任何组合**（起始帧与人物/地点/道具图同时存在，或只有人物/地点/道具图） | `reference`（full-reference） | 六段 |

### 2.1 互斥规则（硬性）

1. **首/尾帧输入与参考输入互斥**：`first_frame` / `last_frame` **不得**与 `reference_image` / `reference_video` / `reference_audio` 混用于同一次提交。
2. 「起始帧 + 角色板 + 场景板」**不能**拆成「`first_frame` 加若干 `reference_image`」——整组统一走 **full-reference**，起始帧也以 `reference_image` 送入，正文用标签编号引用。
3. 产物里的「生成方式」字段仍只有**文生视频 / 图生视频**两个值；模式由用途组合读出，**不写进该字段**。
4. **我们不采用「只给尾帧、由模型推断开场」的路子**：开场必须由分镜已接受的起点决定，交给模型推断会让镜号起点失去权威。因此「结束帧」只在**同时绑定起始帧**时出现。

### 2.2 三段与六段字段（字段名用英文；结构见 `specs/h3-profile.md` 第 8.1 节）

```text
Base / 首帧 / 首尾帧（三段）
integrated_multimodal_description: [Shot 1] …
overall_soundscape: …
non_diegetic_music: … | N/A

full-reference（六段，一次整体提交）
subject_definitions: …
summary: …
retention_analysis: …
detailed_description: [Shot 1] …
overall_soundscape: …
non_diegetic_music: … | N/A
```

- **六段是一条提示词、一次提交**，不是六次生成、也不是只提交第一段；从第一行到最后一行整段投喂。
- 切镜用 `[Shot 1]`、`[Shot 2] At 00:03.500, …`；**第一镜不加切镜时间戳**，后续时间递增且落在本次生成时长内。
- 无对白镜也要写清底声与音效；**无非画内配乐时保留 `non_diegetic_music: N/A`**——省略这一层出现过被模型补乐的情况。
- 素材标签 `<Picture N>` / `<Video N>` / `<Audio N>` / `<Subject N>` 的编号按本镜槽位的**顺序**递增，且全文标签写法保持一致；**文档里手写的编号必须与顺序一致**，两套编号不一致时接口不会报错。

## 三、素材上限与取舍

| 项 | 上限 |
|---|---|
| 首帧 | 1 张 |
| 尾帧 | 1 张 |
| `reference_image` | 9 张 |
| `reference_video` | 3 段（每段 2–15 秒，合计 ≤15 秒） |
| `reference_audio` | 3 段（每段 2–15 秒，合计 ≤15 秒） |

规则：

1. 超上限时**在分镜阶段按重要性取舍**，并写明放弃了哪些参考；**不得在正文里假装它们仍然生效**。
2. **不要为了「多模态」把所有资产图都带上**——每镜只绑定它真正可见且需要保持的起始帧、人物、地点或关键道具图。
3. 每张图的「控制 / 不得控制」决定它在正文里被要求保留什么：起始帧只锚定开场构图与姿态，身份锚定长相与体态，地理只锚定空间关系，造型状态只锚定服装与损污。**别让角色板顺带决定构图，也别让场景板顺带决定长相。**
4. 连续段（要上一段的实际视频与实际尾帧）统一走 full-reference：上一段视频作 `<Video 1>` 控动作与声音连续，其实际尾帧作 `<Picture 1>` 只作开场锚点；**不要把尾帧标成 `first_frame`**。
5. `REF-` / `PLAN-` 两类槽位在模式分派上**同权**——模式由用途组合决定，与图片此刻在不在项目里无关。图片由用户在平台侧自行挂载时，正文写法不变。

## 四、对白容量预算与口型归位（本批新增，第 11 维与第 10 维共用）

### 4.1 先算容量，再排开口

> **实测口径（小样本）**：H3 中文约 **4.1 个可发声字/秒**；样本出现过赶词与静默截断，**不能据此确定通用截断阈值**，只作估算依据。

填写要求：

1. 第 11 维人声轨的逐字台词表（`D1`/`D2`…）**必须给出可发声区间**（起止秒点），并与第 10 维时间轴闭合。
2. 用「字数 ÷ 4.1」估算完整发声所需时长；按**实际可发声区间**核对该区间是否装得下。
3. 装不下的处置顺序：**延长镜长 → 拆镜 → 缩短台词**（改台词须回 L2/L5，不得在 L6 自行改写）。
4. 「语速与时机」在提示词里是**生成指导，不是秒级执行保证**：仅追加「自然语速」补不上缺失的发声时间。
5. 无现成音频时用文本估算即可；**不为「精确」自动调用 TTS 或生成服务**（本阶段只做提示词）。

### 4.2 说话人绑定与口型归位

> **实测口径（小样本）**：一镜中远处角色喊话、近处角色正对镜头且不说话，**现行写法 3 次里 2 次口型落在近处未说话者脸上**；补上「未说话人明写闭嘴 + 说话人出画或背身」两条后，**3 次全部正确**；19 条样本发声基频都在说话人应有的区间内——**模型没选错声音，是口型落到了画面里最显眼的正脸。**

写法（三条，按优先级）：

1. **优先靠调度**：能安排时先让不说话的人出画或背身（实测该情形下两种写法 12 次全部正确）。
2. **说话人第一次出现时**在 `<d>` **外**交代他在画内还是画外、以及音色（年龄 / 性别 / 高低），台词紧跟在**他本人的可见动作句之后**，不集中列在正文末尾。
3. **台词期间画里还有别的正脸时**，把那个人明写成不说话，例如 `The messenger does not speak; his lips remain completely closed.`。

其它口径：

- `<d>` 内**只放语言标签与逐字台词**，不放秒数或表演指令；中文台词保持原文，写作 `<d>[Chinese] 逐字台词</d>`，由稳定说话人 ID（`S1`/`S2`）引出；full-reference 中同时写 `<Subject N> (Sx)`。
- 同一次生成内，跨切镜的已接受对白可用 `<scenetrans>` 并声明声音连续；它**不增加总时长**，也**不能保证两个独立 job 之间的音频无缝衔接**。
- `<cutoff>` 只用于剧本已要求的截断，**不得用来处理装不下的完整台词**。
- 复用已有音频：只参照音色/情绪用 `reference`（会重新表演，不能拿参考音频长度当新台词时长）；整条最终音轨原样复用用 `fully_copy`，只用对白层另加环境声用 `partially_copy`。复用到的发声区间必须完整容纳，**不为适配镜长压缩语速**。
- 生成后**必须核听**逐字内容、语速、停顿、尾音与口型落在谁脸上——上述都是生成指导，不是保证。

## 五、时长与生成设置一致

1. H3 的 `duration` **必填**，为 **4–15 的任一整数秒**（不是只有 5 / 10 / 15 三档）。
2. 网页界面或 job 的时长设置 **必须与分镜时长、正文终点一致**；**写在提示词里的秒数不能替代生成设置**。
3. 短动作在合法镜长内完成并保持已接受的终点；**超过 15 秒的镜头回 L4 分镜按闭合状态拆开**，本阶段不偷改镜头秒数。
4. **型号差异**：`MiniMax-H3-Max` 为 5–15 秒、480P / 768P，**仅支持文生与首/尾帧，不支持 full-reference**——不能把本页的参考音频路径或 4 秒下限套到 Max。

## 六、常见翻车与对策

| 现象 | 根因 | 处置 |
|---|---|---|
| 台词被赶读或静默截断 | 只看了镜长没排发声区间 | 回 4.1 重算容量；延长镜长或拆镜 |
| 口型落在没说话的人脸上 | 画面里最显眼的正脸被当成了说话人 | 回 4.2：先调度出画/背身，再补「明写闭嘴」 |
| 正文写了参考图但没生效 | 模式分派错（首/尾帧与参考混用） | 回第二节；整组改走 full-reference |
| 编号对不上 | 手写标签顺序与槽位顺序不一致 | 按顺序重列槽位清单再写标签；接口不会报错，需人工对账 |
| 凭空多了配乐 | 省略了 `non_diegetic_music` | 明明无配乐也写 `N/A` |
| 条尾出现负面词 | 把负向约束当边界写了 | 按 S-21 改为末尾**正向**一致性约束 |
