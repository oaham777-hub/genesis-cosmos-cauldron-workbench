# 参考素材方式：不强制每镜首帧

本规则优先于旧文档中“每镜必须实际分镜图”“纯文字只能非正式测试稿”的规定。不增加阶段或逐镜问卷；按作者选择、实际素材和平台可用能力推断本场默认，保存到 reference-map 与生成单元。作者可随时改，只有职责不清或实际风险阻断时才问。

## 三种方式

1. **人物／剧情图参考**：已有 Lira 人物图或剧情图时优先推荐。每张图分别登记身份、服装、场景、过程动作、构图或风格职责；过程图可以用，不冒称第 0 秒。人物图不代表本镜构图，未传给视频模型的图片不宣称已由模型参考。
2. **严格首帧（可含首尾帧）**：仅在作者要求锁定开头／接帧，或顾问解释必要性并获同意时使用。读实际图片核对本任务第 0 秒的人物、场景和动作起点；“醒来坐起”的首帧应在坐起前，已坐起的图不能冒称起点。尾帧只有实际提供且入口支持时才登记；换机位可重生本镜开头图，不强制与前镜尾帧像素一致。
3. **文字生成**：允许正式输出，但必须有作者确认的人物文字卡／视觉特征和完整场景、空间、动作、光向、台词与连续状态；不得虚构已上传图像、已读图验轴线或人脸已锁定。需要稳定身份时建议人物参考图，由作者决定；实际视频入口不支持文字模式就报告并改用可用方式。

本场默认可一行说明：“现有人物／剧情图先按参考图用，不重做每镜首帧；需要锁住开头时再补。”不是每个镜头都再弹一次三选一。同一场的不同生成任务允许不同方式，写清每项真实素材。

## 不管哪种方式都要有的连续性

独立写全起始画面与每个时间段的动作、对白、表演、摄影机、光影和具体结束状态。换角度允许画面左右变化，但世界地标、人物真实位置、轴线关系、道具、伤势和时间线必须能对上；不能写“同上”“延续上一动作”让模型补。

有前后镜图片时才做读图视觉检查；没有图时做文字空间核对，登记“视觉未验证”，不能把它当成画面已验收。视觉证据不足不是所有文本任务的硬性缺图阻断；已发现实质站位矛盾、对白超时或未经授权的改戏仍应阻断。

## 保存与改动

每个任务记录素材方式、实际素材清单和职责、平台能力依据、具体开头／结束状态、已确认人物／场景／镜头版本以及检查状态。只写提示词或计划生成的图片标“计划”，不能标“已生图”。

用户改变模式、换图或改起点时，先保存 reference-map 与受影响生成任务的新草稿；确认后旧素材对应的质检和提示词过期。没有变化的镜头不批量重做。
