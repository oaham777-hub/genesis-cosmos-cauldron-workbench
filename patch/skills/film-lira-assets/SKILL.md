# 07 Lira 图像资产 / Lira Visual Assets

## 合作方式与试写边界

继承总控的[合作方式](references/cooperationModes.md)和作者本轮目标。正式成果以确认依据为准；试写可使用明确标注的草稿、片段和假设，不把本Skill的生产输入要求当成讨论或返回的硬门禁。作者明确要求修改时直接出新草稿，不再重复询问是否开始；不自动确认、覆盖原件或执行收费生成。

进入本阶段（含直接调用）先执行 [九阶段菜单与保存位置](references/stage-entry-and-paths.md)：显示本阶段中英标题，按规则展示并保存当前阶段菜单选择；所有读写先解析实际项目路径。此入口不改变本阶段的专业边界。

先读取 `references/asset-strategy.md`，记录轻资产或精品资产策略及按场例外，不要求所有场景出图。

读取 `references/source.md` 作为图像提示词方法来源。用户讨论资产修改、要求优化现有资产或从完整作者剧本直接进入 Lira 时，再读取 `references/asset-change-control.md`。用户要同一地点的多角度场景图，或已选择 07-B 时，读取 `references/scene-multi-angle.md`；单纯要多个不同地点时分别建立场景 ID，不把不同地点拼成一个多角度资产。原场景九宫格保留为 07-B 的轻量备选，不作为需要严格空间连续性时的默认方案。

输入可以是 `00-项目管理/artifact-registry.md` 登记的最新已确认剧本（05 专业剧本或作者外部锁定剧本），也可以是用户本轮明确指定的最终剧本、角色卡、场景资料、道具资料或参考图。允许从 Lira 直接开始，不要求前序阶段全部存在。知识库沿用项目已选的方式与授权范围：已启用智能匹配时，按当前人物造型、场景空间和道具任务主动展示真实候选，不要求用户再说检索口令；尚未选择时提供可跳过的入口，不强制装库。推荐不等于采用，未选联合写作不擅自把资料融入资产；已选自己写则继续独立创作。

如果用户只有一份标准作者剧本，没有独立角色状态表、场次制片表和资产需求表，不得直接凭整部剧本猜一套粗资产。按 `ai-film-router/references/screenplay-intake.md` 做接管检查；用户已明确“原稿不改，直接做 Lira／后续制作”即跳过 06，不重问。只有未表态时才问一次是否审查。生成接管报告，作者确认只补生产资料后，先生成 `05-正式剧本/production-breakdown-vNNN.md`，再开始资产输出。

全流程项目从 05 或 06 进入 07 Lira 时，如果最终剧本已经确认（含 06 判定“无需回退”或用户选择跳过/不改稿），但 `05-正式剧本/production-breakdown-vNNN.md` 不存在，也必须先从最终已确认剧本和 01–04 已确认文件生成该生产拆解。生产拆解独立保存，不把专业剧本正文改写成提示词格式。

APP中的LIRA完整提示词先同步为所有同名画布生成节点，作者可以直接在节点查看和修改、单项或主动批量生成。采用提示词不等于图片已出；默认留在07检查资产，不因采用就自动进入08。作者仍可先做一个表演或镜头，未出图只集中提醒一次，不设全资产齐备门槛。资产数量与取舍由作者决定，可新增、移除可选道具、重命名；重新同步不得偷偷恢复作者已移除项，旧文件保留。

标准资产输出为 `07-图像资产/assets-vNNN.md`。文件内按“角色 / 场景 / 道具”分组，并列出每条资产的稳定 ID、状态 ID、来源场次、参考依据与中文生成提示词。同一人物的不同年代、服装、伤势或变身必须归在同一角色 ID 下，不能拆成多个角色。修改单个资产时，在成果登记中写明受影响的资产 ID 与场次；只有真实引用该 ID 的 08 ACTING、09 CINEDANCE 镜头、关键帧和提示词进入过期状态，其他资产与场次继续有效。

分镜图须注明它对应的场次、时间点及用途（起始帧／尾帧／构图参考）。起始帧只呈现该生成单元开始时已发生的状态，不把后续揭晓、道具交付、换位或表情落点提前画进去；相邻单元按已确认剧本的交接状态核对人物位置、手部持物和已露出的道具。高潮关键图可以另列，但不能标成起始帧。文字清单尚未生图时如实标注，不能声称资产已锁定。

用于固定空间关系的无人场景参考须在提示词中写清前景、背景及反射均无人，避免生图额外添加路人；剧本本身需要人群时按原稿保留，不一律清空群众。

实际守卫以登记的文件依赖为单位：多个资产共用一份文件时，先保守标记依赖旧文件的下游待复核；逐 ID 对照确认未变后，才能在新依据下复用原内容。不要把影响范围提示当成脚本已自动理解所有资产 ID，也不为重登记擅自重画无改动资产。独立登记的资产文件才可按其真实文件依赖精确失效。

07-B 默认先给每个需要锁定的主场景建立平面关系、固定地标与世界光向，再输出从真实不同机位看到的多角度图像提示词；只想快速看视觉方向、空间简单或用户点名九宫格时，才改用轻量九宫格。多角度研究板和九宫格都不是视频镜头首帧；交给 09 时只登记已实际生成并验收的单视角图片及其职责。只写出图提示词不等于已经生图或通过视觉验收。不得因为启用 07-B 强制所有一次性场景出图；允许用户指定哪些场景仅用文字描述。

禁止：未经用户授权改写剧本、重设角色弧光、擅自决定整体美术方向、输出表演段落或完整视频提示词。发现剧本问题时停止并建议总控切回 05 剧本阶段或 06 剧本压力测试，不在资产文件中偷偷修剧本。

用户说“你觉得怎么改、帮我分析、给修改建议”时，只进入咨询模式：查看实际资产后给 2 至 3 个候选方向，不修改文件。只有用户明确选择方向并确认资产修改单后，才生成新版本；旧资产不得覆盖。

完成后标记资产版本和“待人工确认”，更新 `00-项目管理/artifact-registry.md` 的当前草稿并停止；用户确认后才登记为最新确认资产版本。

## 人物设定页与描述符（工作台默认，可由作者改）

- 角色资产由完整文本描述符 `descriptor` 与参考图组成；描述符涵盖年龄、体型、面部、服装及状态。后续09独立提示词逐字复用对应描述符，不以角色名省略。
- 先沿用作者已选的本剧画幅（9:16、16:9、21:9或自定义），未指定时先询问一次，不能默认锁定3:2。作者可随时更改，改稿另存。纯白背景、按所选画幅排版，同页三个独立分区：无表情面部正面特写、裁至颈部的正面全身服装视图（不重复画头，非伤害描绘）、背面全身视图。间距一致，身体比例与服装一致；无文字、Logo、水印、环境、其他人物。作者指定其他版式时服从作者。
- 不把示例人物的年龄、衣着或道具套到所有角色；场景和道具不套人物版式。已有确认图与原稿不自动改写。
