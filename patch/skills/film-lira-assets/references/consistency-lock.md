# 一致性锁定规则（门 2）

## 一、为什么需要锁定

一致性是**参考问题**，不是「把长相写进提示词」的问题。身份由 @绑定 / 参考图承担；文字只点名、只写这一条要它干什么、不干什么。

## 二、锁定项（逐资产）

### 角色
| 项 | 内容示例 |
|---|---|
| 脸型与五官 | 面部轮廓、眉形、鼻型、唇形、眼型 |
| 发型 | 长度、分缝、湿度形态 |
| 体型 | 身高感、肩宽、胖瘦、姿态习惯 |
| 服装 | 主色 + 配色 + 材质 + 磨损点 |
| 标志性细节 | 疤、饰品、旧伤、固定动作（**必写，且全片复用**） |
| 声区（表演用） | 音高、气息、语速（交 L5） |

### 场景
| 项 | 内容示例 |
|---|---|
| 光位 | 主光方向、色温、光源属性（霓虹/声控灯/车灯） |
| 色调 | 冷/暖、饱和度倾向 |
| 材质 | 地面反光、墙面新旧、金属锈蚀 |
| 可识别锚点 | 招牌、门牌号、特定灯具、地面特殊痕迹 |

### 道具
| 项 | 内容示例 |
|---|---|
| 尺寸参照 | 与人体部位的比例 |
| 材质 | 塑料 / 金属 / 纸 |
| 磨损与状态 | 折痕、水渍、磨损边缘 |
| 出图规格 | 白底、可抠、无人无手 |

## 三、锁定后的纪律

1. 锁定项写入资产索引，成为 @绑定与提示词的唯一依据。
2. 任何锁定项变更 → 只新增 `vNN` 版本，不覆盖；并在 `05_shots/<场次ID>/scene-registry.md` 登记。
3. 生成出的图与锁定项不符 → 在 `05_shots/<场次ID>/scene-registry.md` 登记差异并等待用户决定重出或新增版本，不在 L3 私自改设定。
4. 跨集使用同一资产时，直接 @绑定，不重新描述长相。

## 四、审计标签

`[锚点缺]`（无可识别特征）、`[锚点冲突]`（两个资产共用同一锚点）、`[漂移]`（生成结果偏离锁定项）、`[无标志细节]`（角色无法被认出）、`[素材抢职责]`

## v2 补充（上游新增）

- 同一角色的配饰与纹样如需变化，必须先在资产清单里登记，禁止在提示词里临时改。
- 场景光源方向以首次出场为准，换景不换光。
