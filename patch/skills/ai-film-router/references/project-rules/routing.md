## 路由原则

- 一次只执行一个专业 Skill。
- 进入任何阶段前先读取 `project-status.md`、`routing.md`、`artifact-registry.md`、`artifact-state.json`、`session-checkpoint.md`、登记表指向的最新已确认上游文件，以及当前阶段启用的参考记忆；09 还读取当前场次登记表。不得依赖聊天窗口自行回忆。
- `session-checkpoint.md` 只保存当前工作进度。未确认想法必须单列，不能升级为正式项目事实；正式权威仍是最新已确认阶段 Markdown。
- 用户确认、否定或修改重要剧情事实，生成较长阶段草稿，切换 Skill，或平台提示上下文压缩时，后台立即更新检查点。成功时只在回复末尾写一行“阶段进度已保存”，不重复弹窗；保存失败必须马上说明。
- 用户可明确切换到任意阶段，不强迫补齐无关前序。
- 按本轮合作档位使用`../cooperationModes.md`：进阶/高手可先用未确认上游草稿试写，说明依据与假设；新手默认推荐路径，明确要求跳步或返回时也可执行。不得把正式采用的依赖门槛用来锁死讨论。
- 未经用户明确要求和确认，不改掉其他阶段已确定内容；用户可主动回退和修订。
- 修订草稿未确认时不作废下游；新上游确认后，只把真实依赖旧版本的下游标记为“已过期-禁止使用”。
- 05 剧本确认后或 B 入口带入完整剧本时，询问用户是否进入 06 剧本压力测试；06 报告仅诊断不代改剧本，须获作者采纳并授权后才按病灶回退 01–05。
- 知识桥不是创作阶段。新项目首份创作成果前必须主动显示一次 A/B/C 选择，但只有用户选择 B/C 或另行明确调用后才检索。
- 专家桥不是创作阶段。只显示与当前项目有关的具体推荐；不选则照原流程，同阶段不重复提示。
- 选定前不读专家正文。选定后先小范围定向读取，证据不足时继续补读，不为省 Token 猜测。
- 只有用户确认的知识卡可以列入“本阶段方法来源”；候选检索结果不能直接进入创作。
- 已确认方法写入 `reference-memory.md` 后可以跨阶段复用；每个阶段读取完整文件，再按使用范围加载。故事类方法默认贯穿 01–05。
- 权威顺序固定为：用户本轮要求 > 最新已确认项目文件 > 启用参考方法 > 模型通用知识。
- 第 05 阶段整合前必须读取所有最新已确认的上游阶段文件；参考方法不得覆盖大纲、角色、世界观和场次事实。
- 切换阶段时先保存当前检查点，再把 `routing.md` 的“本阶段允许读取”改成新阶段最小资料集合。上一 Skill 的无关方法、候选想法和未启用资料不得进入下一阶段。
- 进入 07 前若缺生产资料，先从标准剧本提取角色状态、场次、时长、资产和表演需求；不得擅改剧情。
- 完整标准剧本缺时长预算时，由作者剧本接管生成逐场初估，不强迫重跑 04；下一步按当前场次缺项进入 07、08 或 09。
- 从零项目的 04 只提供场次预算；05 每次完整剧本草稿都要按准确对白和动作生成成稿时长复核。硬时长超限时在确认 05 前处理，普通偏差登记后交给 08/09 继续精算。
- 09 先按项目默认或本场覆盖档位展示适量方案；默认只问一次但允许以后更改，不因仅换档作废已确认镜头。确认导演方案、镜头规划、生成单元与空间图，再按实际职责绑定参考素材；不强制每镜首尾帧。严格首帧才锁开头画面，有图做视觉质检，无图标视觉未验证。镜头规划与提示词分别留版。内部镜头与一次生成单元是两层时间，30 秒任务可以多镜头。
- 09 按场次建立独立目录和登记表；镜头清单、生成单元、连续性、关键帧与各模型提示词分别保存和登记。镜头清单有新确认版时，旧生成单元及相关提示词过期；只改生成单元时受影响提示词过期，新包只重编受影响内容。
