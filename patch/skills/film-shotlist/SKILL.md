# 07.5 镜表 / Shotlist

把一场戏从"散文"变成"可逐镜决策的索引"，同时不丢掉导演意图。**镜表只负责一致，意图放镜卡，提示词由下游编译。**

## 一、进入条件

- 路由已把阶段选为 07.5 SHOTLIST，或作者明确要求拆分镜 / 出镜头表 / 定机位。
- 本层是插入件，编号 07.5：在 07 资产之后、08 表演之前。若作者只是要文字讨论，不必进本层。
- 进入后先确认三件事：哪一场戏、这一场的剧本条目范围、已有资产（人物/场景/道具图）的编号与采用状态。缺任何一项只提示一次，允许带缺口继续出粗分镜。

## 二、最小输入

1. 已确认或试写的剧本场（含场号、场次标题、动作与对白）。
2. 该场涉及的角色、场景、道具资产编号（可为空，空则镜表里写"待绑定"）。
3. 作者的镜头偏好或参考片（可选，没有就不问）。

## 三、标准输出

| 件 | 路径 | 说明 |
|---|---|---|
| 镜表（主件） | `05_shots/epNN-shotlist.md` | 一场一文件，每镜两行，列见第四节 |
| 镜卡（按需） | `05_shots/shots/epNN-Snn.md` | 只在某镜需要展开意图/备选/摄影笔记时创建 |
| 连续性登记 | `05_shots/epNN-scene-registry.md` | 本场资产与外观状态，供跨场接缝核对 |

**不要**另建追踪文件：缺失与待决定一律写在镜表的"状态"列里并给理由。

## 四、镜表规格（两行制）

列固定为 8 列，完整字段定义与示例见 `references/shotlist-spec.md`：

- 第 1 行：镜号 ｜ 对应条目 ｜ 时长 ｜ 景别 ｜ 机位与轴线 ｜ 镜头语言 ｜ 首帧与参考绑定 ｜ 状态
- 第 2 行（同一镜号续行）：摄影 ｜ 画面 ｜ 光影

- **镜头语言**是独立字段，必须写全五项：机位意图 / 运镜节奏 / 构图策略 / 视点归属 / 景别理由。缺一不得下传。
- **首帧与参考绑定**只写资产编号，不写描述；描述在资产库，避免两处维护。
- 列多时用两行制，**不允许删列**。删列等于丢信息。

## 五、状态机（防假确定性）

状态只允许四种：`已定` / `待定` / `待确认` / `废弃`。

- 填 `待定` 或 `待确认` 必须紧跟一句理由（例：`待定（等 07 出场景图后再定机位）`）。
- **禁止空白**，禁止用默认值（中景、50mm）冒充已定。
- 整表进入"锁定版"前，`待定` 与 `待确认` 必须清零；粗分镜阶段允许大量存在。

## 六、硬性规则

1. 镜号连续、不跳号；废弃镜保留行并标 `废弃`，不删行。删行会让下游编号错位。
2. 一个片段 = 一个镜号 = 一份提示词 = 一个视频节点；本层只负责镜号与镜表。
3. 同一张图不能既当身份参考又当首帧，绑定前先查资产采用状态。
4. 越轴必须先写理由（`越轴：情绪断裂，需正反打承接`），否则视为错误。
5. 摄影参数只写"方案"，不猜模型采样参数（seed、步数、采样器一律不写）。
6. 镜表未确认不得进入 09 编译——这是门，不是建议。

## 七、决策树

- 作者只给一场戏、没有剧本条目 → 先按场次正文粗切，标 `待定`，不做精确时长。
- 已有资产图但未采用 → 照常出镜表，绑定列写 `待采用(资产号)`。
- 一场戏超过 20 镜 → 按叙事段落拆成 A/B 组，组内镜号连续。
- 作者要改已锁定镜表 → 只动被点名的镜号，其余保留，废弃镜标 `废弃` 不删。
- 缺首帧但要求出提示词 → 停下，先补首帧或用文字描述首帧并标注"文字首帧"。
- 都不满足 → 回到 00 路由，重新确认阶段。

## 八、下游交付

- 08 表演：按镜号逐镜写表演块，引用镜表的景别与镜头语言。
- 09 提示词：按镜号逐镜编译，镜表行数必须等于提示词份数；编译前先过门禁。

## 九、本层自检（交付前逐项过）

- 8 列是否齐全，两行制是否同镜号对齐。
- 状态列是否无空白、`待定`是否都带理由。
- 镜号是否连续、废弃是否保留行。
- 镜头语言五项是否写全。
- 参考绑定是否只写编号、是否与资产采用状态一致。
- 时长合计是否与场次目标时长量级相符（偏差超过 50% 要说明）。
