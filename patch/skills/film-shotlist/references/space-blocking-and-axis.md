# 空间类型、调度与轴线（L4 · reference）

> 用途：镜头设计前的第一步——先认空间，再排调度，最后才谈镜头。防止「物理不可行的镜头」与「越轴正反打」。
> 来源：`imports/seedance-storyboard-3.0`（`blocking`：spatial-language / axis-and-coverage / master-shot-technique）、`imports/xiaomo-storyboard`（小墨 6.0 §9 场景空间类型识别）。

## 一、空间类型识别（先判类型，再选镜头）

| 空间类型 | 特征 | 允许的镜头 | 禁止的镜头 |
|---|---|---|---|
| 开阔外景 | 天/地/远山，尺度大 | 大远景、升降、摇镜、鸟瞰 | 无 |
| 街区与巷道 | 两侧遮挡、线性强 | 跟拍、横移、纵深推进 | 大幅鸟瞰 |
| 室内标准间 | 四面墙、天花板低 | 中景、近景、固定、小幅推拉 | **大远景、鸟瞰、升降** |
| 室内狭窄（走廊/车内/电梯） | 单向纵深、转身困难 | 正面/侧面近景、纵深直线跟拍 | 环绕、大幅移动 |
| 半开放（门口/阳台/窗边） | 内外两种光 | 过肩、逆光剪影、门缝构图 | 无理由的向外大远景 |
| 巨物/史诗空间 | 超尺度对比 | 极远景、仰角、尺度递退 | 无 |

> 判定顺序：**物理可行性 ＞ 叙事情绪 ＞ 多样性指标**。三者冲突时前者压倒后者。

## 二、调度与走位（blocking）

1. **主镜（master shot）法**：先写一个能覆盖全场关系的完整走位，再拆成覆盖镜头（coverage），最后补插入镜头（insert）。三种镜头的用途不得混淆：
   - 主镜：交代空间与关系全貌；
   - 覆盖：正反打与近景切换，服务对白与反应；
   - 插入：道具、手、屏幕等**必须有信息的**细节。
2. **走位必须写起止**：`从门口 → 走到桌边（3 步）`，不写「走过去」。
3. 人物与道具的空间关系必须写清参照物（**绑定场景锚点名称**），禁止「左边/旁边/对面」这类无参照的模糊方位词。
4. 相邻镜头的落幅与起幅要能接得上：上一镜落幅＝下一镜起幅（或形成有意义的反差）。

## 三、轴线与越轴

| 规则 | 内容 | 违反后果 |
|---|---|---|
| **180° 轴线** | 同一段对话/动作中，摄影机保持在同一侧；人物左右关系不得互换 | 观众读成两个方向，人物关系错乱 |
| **30° 规则** | 相邻两镜的角度差 ≥30°，避免「跳接感」 | 画面像卡帧 |
| **视线匹配** | A 看画外 → 下一镜切到 B（或物） | 观众读不出「他在看什么」 |
| **越轴处理** | 必须越轴时，用运动镜头越过、或插入中性镜头、或切换轴线 | 无过渡的越轴＝事故 |

**标注方式**（写进镜头表「轴线」列）：`轴线：门内外（左 A / 右 B）`、`越轴：由 S07 运动镜头带过`。

## 四、门与缝：乾坤鼎常用空间母题

- 门缝/缝隙类构图：**缝宽决定信息量**，缝宽一旦确定，跨镜头必须一致（否则观众误判空间）。
- 门内外对峙照例走「同侧不走越轴」原则：内外双方各占固定一侧，直到门真正打开才允许换轴（换轴本身成为叙事事件）。
- 门的开合、遮挡与显露＝信息揭示节奏：先声后形、先局部后整体。

## 五、自检

1. 每个镜头是否先判过空间类型？是否出现该空间类型明令禁止的镜头？
2. 走位是否写清起止与步数？参照物是否绑定了场景锚点？
3. 对话段是否守住 180° 轴线？相邻镜角度差是否 ≥30°？
4. 主镜 / 覆盖 / 插入三类是否用在其位（插入镜头是否真的带信息）？
5. 空间事实（家具位置、开门方向、光从哪来）是否全场一致？
