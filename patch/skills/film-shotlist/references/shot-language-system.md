# 镜头语言体系（L4 · reference）

> 用途：为镜头表第 4 维「镜头语言」提供取值与判据。写作顺序固定：**景别 → 焦段 → 机位角度 → 运镜 → 构图与视点**。
> 来源：`imports/director-studio`（04 AI 视频分镜）、`imports/xiaomo-storyboard`（小墨 6.0 / 6.3）、`imports/seedance-storyboard-3.0`（`camera`、`shot-design`）、`_incoming/cinematic-shot-design电影镜头`。
> 上位规范：`specs/cinematography.md`（三要素/焦段/画幅/白平衡/拍摄方式/焦点）。

## 一、景别序列

| 景别 | 信息量 | 典型用途 | 忌用 |
|---|---|---|---|
| 大远景 / 远景 | 环境与处境 | 定场、孤立感、时间压力 | 人物对话的常态 |
| 全景 | 人物与空间关系 | 走位、动作完整链 | 交代情绪细节 |
| 中全景 / 中景 | 身体语言 | 对话默认、动作过渡 | 长时间停留 |
| 近景 | 面孔与手 | 情绪锚点、信息确认 | 连续三个近景 |
| 特写 / 大特写 | 物件与细节 | 关键道具、屏幕文字、决定性动作 | 无理由的堆砌 |

**硬规则**

1. 情绪越强，景别越紧；动作越大，景别越松。
2. 任一组镜头内景别**必须有变化**，禁止连着三个近景。
3. **景别跳跃**（如远景直接切大特写）只用于刻意的重锤，且必须写清理由；相邻镜默认不跳两级以上。
4. 非人物镜头（物件/环境/空镜）与人物镜头同等预算，**每个镜头都必须有存在理由**，能删则删。

## 二、焦段与光学

- 标准 50mm＝人眼基准；中长焦 85mm 起做面孔与人像压缩；广角 24mm 以下做空间夸张与压迫。
- 焦段与景别绑定写（`中景 / 85mm`），不写「长焦一点」这类模糊表述。
- 浅景深（f/2.0 以下）用于隔离主体，必须同时给出**焦点落点**（谁/哪只手/哪个数字）。
- 同一场戏内白平衡与色温保持一致，只允许因光源变化而调整。

## 三、机位角度

| 角度 | 心理效果 | 使用条件 |
|---|---|---|
| 平视 | 中性、可信 | 默认基准线 |
| 微仰（约 10°） | 抬升主体、坚定 | 主体占据主动权时 |
| 大仰角 | 权力顶点、压迫感 | 全片限量使用 |
| 微俯（15°~25°） | 处境压迫、被观看 | 交代空间与弱势 |
| 大俯角 / 鸟瞰 | 渺小、宿命 | **室内禁用**（物理不可行） |
| 荷兰角 | 失衡、不安 | 全片占比极低（如每集 ≤1 镜） |

- **物理可行性优先**：室内空间不允许大远景鸟瞰与升降镜头；先看空间类型再选机位（见 `space-blocking-and-axis.md`）。
- 角度倾斜与俯仰必须由情绪买单；**没有情绪理由的激进机位视为炫技**。

## 四、运镜

| 运镜 | 绑定条件 | 备注 |
|---|---|---|
| 固定 | 对话、静止特写、关键首帧 | 默认项，占全片多数 |
| 横移 / 摇镜 | 展现场地、跟随视线 | 速度必须写清（缓慢/匀速/急停） |
| 推 / 拉 | 推＝情绪收紧，拉＝抽离或结束 | 推拉幅度与用时必须标 |
| 跟拍（手持/稳定器） | 行走、追逐、紧迫 | 手持写清烈度等级 |
| 升降 / 轨道 | 空间揭示 | 室内慎用 |
| 复合（跟拍＋推） | 情绪与动作同步升级 | 必须写清主次，不同时上三种以上 |

**频率上限**：同一单元内避免连续三种动态运镜；运镜风格在全片内保持统一，形成「激进有对比、有落差」而非处处用力。

## 五、构图与视点

- 走位构图法：先定人物在画框的位置（左/右/中、上下三分之一），再定前后景与留白方向。
- **视点必须明确**：客观视点（观众看）/ 主观视点（角色看）/ 上帝视点（无人称俯瞰）；同一单元内不无故切换视点。
- 引导线、框式构图、遮挡前景：可用来强化纵深，但**禁止用 fog / haze / blur 当万能纵深**（见 `specs/lighting.md` 纵深主层机制）。
- 竖屏（9:16）默认：人物纵向占位优先，横向信息靠层次而非宽度；横屏（16:9）默认：左右留白承担空间叙事。

## 六、自检（每条镜头表写完后过一遍）

1. 每个镜头是否同时写清景别 / 焦段 / 机位角度 / 运镜 / 视点五要素？
2. 连续三镜的景别是否全同？运镜是否同质？
3. 是否出现无情绪理由的大仰角、荷兰角或鸟瞰？
4. 焦点落点是否与叙事信息一致（关键道具是否在实焦平面内）？
5. 激进手法是否集中在情绪节点，而不是平均分布？

> 违规示例：`中景，摄影机缓缓环绕人物` —— 缺焦段、缺角度、缺环绕理由。
> 合规示例：`中景 / 50mm / 平视微仰约 10° / 固定 / 客观视点；焦点在桌面那张纸`。
