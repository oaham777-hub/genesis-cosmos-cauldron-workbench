# 场景覆盖与首帧分镜（L4）

> 状态：**已完成**｜版本：**v01**｜溯源：**自写件**（方法来源：用户投喂源 **第 29 号源** `chaoge-craftsmanship-2.12.4` 的 `first_frame_storyboard.md` ＋ `scene_360_coverage.md` ＋ `spatial_preflight.md`；该源**无 LICENSE 文件**，按**用户投喂源**使用；**本件为方法提炼，未复制其正文**）
> 用途：把"**第一眼看什么**"（首帧）与"**同一个场景还有哪些面**"（定点 360 补角）两件事管起来。镜位与轴线通则见 `space-blocking-and-axis.md`；镜位字段体系见 `shot-language-system.md`；控制图见 `control-image.md`。

---

## 一、为什么这两件事归一处

| 事项 | 决定什么 | 失控后果 |
|---|---|---|
| **首帧分镜** | **第一注意力**、空间方向、身体裁切、开场钩子 | 第一眼看错东西 ⇒ 整条镜头的戏剧职责落空 |
| **定点 360 补角** | 同一机位**四周**的空间事实完整性 | 只出正面 ⇒ 反打与背面全靠模型即兴，跨镜撞车 |

两者都是**演员/机位落地前**的空间事实固化件，故同属 L4 前置。

## 二、首帧分镜（导演预演件）

### 2.1 触发规则（**不得主动扩用**）

| 场合 | 处置 |
|---|---|
| **项目第一个视频生成单元** | 方案确认后**必须**生成 1 张（让创作者直观看见方案落地） |
| **第二个及后续单元** | **默认不触发、也不主动建议**；创作者明确要求"看构图 / 生成首帧分镜"才做 |
| **已有尾帧 / 站位截图** | **优先用截图**提取人物位置、朝向、姿态、道具与环境状态；仅当创作者仍要求时才另画 |

**站位依据必须统一登记为以下之一**（不得含糊）：
`确认后生成并内部检查的首段资产参考分镜图` / `用户上传起始帧` / `上一批尾帧截图` / `已确认站位·场景参考图` / `第一帧技术预演·对外首帧效果` / `用户请求的真人比例分镜图`。

> **尾帧截图只继承可证实项**：位置、朝向、身体姿态、道具、环境状态。
> **不得继承**：模糊脸、拖影、错误身份、压缩瑕疵。
> 截图若还要作为正式首帧上传，须在映射表中**另列为连续性素材**；仅供导演判断时**不分配图号**。

### 2.2 参考资产选择（**最少充分集合**）

1. 每个首帧可见的主要人物**各选 1 张已确认身份母板**；
2. **1 张**决定首帧空间几何的主场景图；
3. **仅当**关键道具在首帧承担构图或动作职责时才加道具图；
4. **不传入**本单元不可见、未确认、重复角度或仅供以后使用的素材。

> **必须真的传入**（绝对路径进图像工具），**不得**只在文字里声称"参照资产"。
> 参考图只锁定**可见身份 / 服装 / 体型 / 道具外观 / 场景几何**；**不复制**资产图的白底、分栏、文字、正背排版与原始摄影角度。

### 2.3 构图锁定字段（12 项，**逐项写全**）

```text
画幅：16:9 单幅横图
景别：[大全景/全景/全身/中全景/中景/半身/中近景/近景/特写/大特写]
主角身体裁切：[明确写从哪里到哪里]
次要人物身体裁切：[逐人说明]
摄影机：[焦段、离地高度、俯仰、与主体关系]
机位与轴线：[相对人物运动/视线/关系轴的观看方位 ＋ 180° 轴线连续性]
画面位置：[逐人写画面左/中/右 与 前/中/后景]
运动与威胁留白：[哪一侧保留运动、视线对象、危险来源或逃生空间]
姿态与朝向：[重心、朝向/背向摄影机]
关键地标：[只保留决定构图或动作的 1~3 项]
首个注意力焦点：[只写 1 项]
构图关系：[前中后景、遮挡/引导线/负空间/主体偏置中实际使用的 1~2 项]
前 1~3 秒视觉钩子：[动作、异常、威胁、矛盾或未回答问题]
```

> **不能只写景别而不写身体裁切**；**景别名与裁切事实冲突时，以明确身体裁切为最终判定**，并回写修正景别名。

**景别最低可读标准**

| 景别 | 最低可读标准 |
|---|---|
| 大全景 / 远景 | 人物可较小，但**人体轮廓、移动方向、人与环境尺度关系**必须可辨 |
| 全景 / 全身 | **头顶到鞋底完整可见**，脚下留环境空间，**不得切脚** |
| 中全景 | 头顶至膝下或小腿，**必须明确裁切点** |
| 中景 / 半身 | 头顶至腰或胯；**承担剧情的手部动作必须完整可见** |
| 中近景 | 胸口以上；眼神、面部朝向、肩部关系清楚 |
| 近景 | 头肩或面部占主要画幅，**不伪装成半身** |
| 特写 / 大特写 | 只保留剧情所需局部（眼 / 手 / 脚 / 道具），**明确是哪个局部** |

### 2.4 生成与检查

- **图像内不得出现**：文字、姓名、箭头、尺寸线、分栏、漫画格、图例、摄影机图标。
- **不得出现**：火柴人、线条小人、简笔人、抽象人形、剪影、人台、假人、人体模型、木偶、卡通比例、Q 版、彩色成稿、照片、3D 渲染。
- **不得新增**：人物、道具、动作（只表达**首帧可见事实**，不在一张图里塞后续动作或多个时间点）。
- **目测检查 12 项**：人物身份 / 身体裁切 / 人数 / 左右位置 / 前后层 / 朝向 / 动作 / 地标 / 第一注意力 / 构图关系 / 运动与威胁留白 / 180° 轴线 ＋ 开场钩子。
- **失败处理**：**自动重画 1 次**；第二次仍失败 ⇒ **说明未通过项**，并以**已确认的文字预演**为首帧依据继续编译，**不追加确认回合**、**不用火柴人顶替**。

### 2.5 使用边界

1. 首帧分镜**不进人物/道具/场景资产表、不自动分配图号**；创作者主动指定其为正式首帧并确认后，才作连续性素材映射。
2. 只允许让图像**贴合已确认方案**；**正中、斜轴、侧面、背面、过肩不因形式本身判失败**——只查关键动作、人物关系、空间方向、轴线是否清楚。
3. 创作者要求**实质改变**景别、机位、构图逻辑、第一注意力或原文边界 ⇒ **回上游重新确认**，**不得伪装成"局部重画"**。
4. 3 人以上交叉走位 / 打斗 / 跨房间 / 复杂接触，可在内部建**确定性 2D 调度图**；**内部调度图 ≠ 对外首帧分镜**。

## 三、场景定点 360° 补角（**显式请求才用**）

### 3.1 用途与边界

- 触发条件：创作者**明确提出**"定点 360 度补角 / 360 视频补角 / 360 度旋转抽帧"，**且**一张场景主图**已确认**。
- **必须**把该确认图**上传到平台的首帧 / 图生视频槽位**作为**真实首帧**——**不得**只当普通视觉参考。
- 目标：从该图的**原始机位、朝向与构图**出发，用**一段 10 秒连续旋转视频**推演同一机位四周空间，再**截取静态帧**补进场景视图库。
- **这不是绕场景外部飞行的环绕镜头**：摄影机**光心固定在场景内部一个物理点**，只绕自身垂直轴旋转。
- **单图看不见的左右与背面必然含模型推演** ⇒ **未经创作者确认只能是候选**，**不得覆盖主图或项目记录中的既有事实**。
- **优先级**：建筑毛坯骨架（墙体、门窗、楼梯、壁炉/烟囱、剧情固定设施）**优先于**模型推演；可移动家具**可在采用视频或抽帧后冻结为场景事实**。

### 3.2 方向卡（写进提示词的场景与空间部分，不另作外部导演卡）

以图 1 当前朝向为 **0° / 前方**，**顺时针**：90° 右方 · 180° 后方 · 270° 左方 · 360° 回到前方。

| 项 | 要求 |
|---|---|
| **前方** | 严格复现图 1 可见的地形、墙面、门窗、家具、道路或自然地标 |
| **右方** | 从图 1 **右缘连续推演**：地势高低、通道、边界、固定结构 |
| **后方** | 写明摄影机**背后**的完整空间，**不复制前方**，**不凭空增加**剧情性建筑或道具 |
| **左方** | 从图 1 **左缘连续推演**，与前方、后方**自然闭合** |
| **中心锚点** | 摄影机所在位置、高度、水平朝向，以及距主要地标的**大致关系** |

> 室外重点：地势、可通行面、**树林密度**、山体、建筑、天际线。
> 室内重点：**四面墙**、门窗、垭口、壁炉、楼梯、通道，以及主图中已确认的可移动家具。
> **方向卡只描述当前场景**，不引用拓扑图、前后剧情或未上传图片。

### 3.3 镜头参数（**硬约束**）

| # | 约束 |
|---|---|
| 1 | 全程 **10 秒一镜到底**，**无切镜、无转场、无遮挡伪装断点** |
| 2 | **第 1 帧与上传图完全一致**：同一机位坐标、机位高度、焦段、水平线、朝向、构图、曝光、色调、可见结构 |
| 3 | **光心、三脚架位置与高度完全固定**，只绕自身垂直轴**顺时针匀速**旋转 360°（以俯视机位为判定，画面表现为镜头持续向右摇摄）；**全程不得逆转** |
| 4 | **恒定角速度**：平均 **36°/秒**；**无起步加速、结束减速、缓入缓出、中途停顿、忽快忽慢** |
| 5 | **尾帧精确回到起始朝向与原始构图**（重新对齐水平线、画面边界、主体位置、透视、曝光）；**不多转、不少转、不越过起点** |
| 6 | 机身**不得**平移、升降、俯仰、侧倾、推拉、变焦 |
| 7 | 焦段：小型室内 **28~35mm**；中大型室内与室外 **35~50mm**；全程**同一支直线投影定焦**，**无鱼眼、无桶形畸变、无边缘拉伸** |
| 8 | 高度：室内默认约 **1.5m** 人眼高；室外出主图机位反推；**整段不变** |
| 9 | 为便于抽帧：**低运动模糊、稳定曝光、清晰材质** |
| 10 | **光源固定在世界坐标**：相机转向时光从画面不同方向出现，但**阴影、天气、色温、环境亮度不得重置** |

**声音**：仅当前场景真实环境声；**无对白、无背景音乐**。

### 3.4 验收与抽帧

**先检查**：第 1 帧是否真实复现上传图 · 旋转是否始终顺时针匀速 · 有无反转/停顿/缓入缓出/机位位移 · 第 10 秒是否精确闭合 · 前后左右是否出现**重复**建筑门窗家具 · 道路地势是否断裂 · 焦段/曝光/天气/光源是否漂移 · 抽出的单帧是否清楚。室内还要核对推演出的门窗、楼梯、壁炉是否**与已确认毛坯骨架冲突**（**冲突方向不得采用，但不因单个错误方向否定其他可用抽帧**）。

**抽帧检查点**：若近似匀速，优先看 **0 / 1.25 / 2.5 / 3.75 / 5 / 6.25 / 7.5 / 8.75 秒**（对应 前 / 右前 / 右 / 右后 / 后 / 左后 / 左 / 左前）；**最终以视频实际朝向选帧，不机械相信时间码**。

**采用纪律**：抽帧**先登记为候选**，**创作者确认后**才成为正式场景角度资产；采用帧中的**可移动家具位置随之冻结**；**未采用方向不写入项目记录**。
