## 一镜到底与参考视频分层契约（L4）
> 状态：**已完成**｜版本：**v01**｜溯源：**自写件**（方法来源：用户投喂源 **第 29 号源** `chaoge-craftsmanship-2.12.4` 的 `one_take.md` ＋ `loop_engineering.md`（成片反馈与回退顺序）＋ **第 26 号源** `h3-reference-video-prompt` 的 `layer-contract.md`；两源**均无 LICENSE 文件**，按**用户投喂源**使用；**本件为方法提炼，未复制其正文**）
> 用途：判"**这条该不该一镜到底**"、写"**一镜到底怎么落地**"、定"**复刻参考视频时哪些层必须原样保留**"。镜位与轴线见 `space-blocking-and-axis.md`；镜头语言见 `shot-language-system.md`；成片反馈与回退顺序见本件 §五（**成片诊断不属于乾坤鼎环节**，见 S-32）。

## 一、一镜到底的采用门槛（**五条须同时满足**）
才可列为**主方案**：

1. **连续时空**（同一地点、同一时间流）；
2. 摄影机存在**真实可通行路径**（不穿墙、不穿人、不瞬移）；
3. **不切镜能增加**代入 / 压迫 / 实时性（即"不切"本身有叙事理由）；
4. 存在**清楚的主体接力**（视线 / 动作 / 道具 / 入画带动）；
5. 动作、人物、道具总量**在模型稳定范围内**。

**优先拆镜的情形**（命中任一即拆）：

- 跨时空；需要**并行反应**；依赖**多个精确插入特写**；**多次复杂变形 / 破坏**；
- 摄影机**必须穿实体**；**人物接触与道具传递过多**。

---

## 二、叙事增益（**不是"长"就好**）
1. 一镜到底**至少出现 2 次有意义变化**：视点 / 主体 / 景别 / 焦点 / 人物关系 / 情绪反转。
2. **持续跟拍而没有新信息 ⇒ 缩短**。
3. **每条只保留 1 个核心创意**；**不叠加**无动机环绕、极端畸变、树干遮挡、炫技转场。

---

## 三、写法
1. 与多镜**共用同一套主体栏目**（本项目为 L6 的六主体栏目；模板见 `06-prompt/templates/`）。
2. 【镜头序列】内**只设一条**：`镜头1（0.0—X.X 秒｜一镜到底，[拍摄策略]）`；**完整叙事时间只标这一次**，正文不再分时间段。
3. 开头写**可独立理解的首帧**，随后自然描述人物、摄影机、焦点、声音**随动作的变化**，收束到**最终可见状态**。
4. **只保留必要拍摄参数**；不另设起手式、连续时间轴或落点栏目。
5. **全程不切镜、不瞬移、不以遮挡伪装断点**；可选的 1 秒站位交接**在叙事单镜后另列**。
6. **关键因果必须紧邻**；同一瞬间写"**同时 / 立即**"，**避免**"人物先停顿反应、物体再延迟掉落"。

---

## 四、摄影机物理（**最常翻车处**）
| # | 规则 |
|---|---|
| 1 | **定焦镜头全程焦段固定**；允许移动、升降、摇俯、焦点转移。需要改变焦段时，**明确使用变焦镜头并写明叙事作用** |
| 2 | **明确**人物与摄影机的**相对方向、坡度、屏幕运动、路径**；**不得让模型自行选择环绕方向** |
| 3 | 真长镜头**不使用**树干、人体、黑场、闪白或相似物的**整幅遮挡伪装切点** |
| 4 | 摄影机**不得穿墙、穿树、穿人**，**不得无轨迹从正面跳到背面** |
| 5 | **主体交接**必须由**视线 / 动作 / 道具运动 / 人物入画**带动 |

## 五、复杂度与回退
**优先配置**：同一地点 · **1~3 名**主要人物 · **1 个**关键道具接力 · **1 次**动作峰值。

**高风险标记**（同时出现即标）：儿童摔倒 · 复杂抱起 · 多人接触 · 精确道具滚动。

**回退阶梯**（同类物理错误**连续 2 轮**仍失败时，**停止增加禁止词**，按序尝试）：

1. **减少当前镜头职责**；
2. 将复杂动作**拆为前后两个内部镜头**；
3. 改用**更清楚的机位**或**可见地标**；
4. **缩小当前原文范围**；
5. 增加**首帧预演图**或高风险**站位图**（见 `scene-coverage-and-first-frame.md`）；
6. 若下一单元可独立切开，**放弃严格同动作连续**。

**一镜到底专项回退**：先检查**文字是否把连续因果拆开**；确认文字无问题后，回退为「**开场长镜头 ＋ 关键动作短切**」，或在**主体接力点拆成两条**。

> **冻结成功部分**：局部可修时**不重做已经成功的全部内容**；一次只改**最可能负责的那一层**。
> 成片结果诊断与八层故障定位（风格摄影 / 身份资产 / 空间连续 / 动作物理 / 表演台词 / 镜头节奏 / 声音音乐 / 模型容量）**不属于乾坤鼎环节**——乾坤鼎交付止于提示词，出片与合格判定由**用户**在其他平台自行完成（S-32）；本件只提供**回退顺序**供用户参考。

## 六、参考视频分层契约（**复刻 / 二创时的判据**）


## 6.1 四种策略（**逐层单独选，不默认全锁**）
| 策略 | 含义 |
|---|---|
| `preserve` | 内容、顺序、功能**都保持不变** |
| `adapt` | 保留**功能 / 节奏 / 轨迹**，允许按新素材调整表现 |
| `replace` | 用新内容**重新设计** |
| `omit` | 用户**明确要求删除** |

## 6.2 可控制的 12 层
`timeline`（总时长·分段·镜头顺序·卡点）· `camera`（景别·角度·机位·运动）· `composition`（主体位置·画面重心·前后景关系）· `actions`（顺序·方向·轨迹·速度·停顿）· `transitions`（硬切·遮挡·蒙版·匹配剪辑·变形·定格）· `text`（字幕内容·位置·动画·时机）· `audio_timing`（音乐卡点·音效触发点）· `audio_style`（音乐类型·音色·环境声·旁白风格）· `visuals`（人物·妆发·服装·场景·光线·色彩·材质）· `props`（外观·数量·位置·轨迹·功能）· `product_brand`（产品·包装·标签·品牌·收尾展示）· `narrative`（信息顺序·冲突·卖点·情绪曲线·结尾作用）。

## 6.4 容易误判的六条（**必须分别记录**）
1. 蒙版的**出现、收拢、变形**可 `preserve`；**蒙版画成什么**归 `visuals: replace`。
2. 道具的**挥动方向与遮挡功能**可 `preserve`；**外观**可 `adapt`。
3. **换装发生的时间**可 `preserve`；**每套服装**可 `replace`。
4. **字幕时机**可 `preserve`；**文字内容与字体视觉**可 `replace`。
5. **鼓点与动作触发点**可 `preserve`；**乐器与音色**可 `replace`。
6. **「保持运镜」≠「保持动作」** —— 两者**必须分别记录**。

## 6.5 契约件字段（写入项目，供下游读取）
`mode`（`selective_remix`）· `source`（参考视频 / 原始提示词 / 取证方式）· `output`（解构件 / 提示词 / 目标模型）· `policy`（**12 层各一策略**）· `locked`（本次确需保留的时间段与**最短最稳定的动作·机位·转场短语**）· `validation` · `limits`（如字符上限）。

> `locked.required_phrases` **只写最短、最稳定的动作 / 机位 / 转场短语**，**不要混入将被替换的人物、服装、背景与产品名**。
