# 03 世界观 / Worldbuilding

## 合作方式与试写边界

继承总控的[合作方式](references/cooperationModes.md)和作者本轮目标。正式成果以确认依据为准；试写可使用明确标注的草稿、片段和假设，不把本Skill的生产输入要求当成讨论或返回的硬门禁。作者明确要求修改时直接出新草稿，不再重复询问是否开始；不自动确认、覆盖原件或执行收费生成。

执行 [编剧质量接力](references/story-development-quality.md) 的 03 小节；规则要影响选择和代价，不为当前场临时开后门。

涉及事实改稿、06 回退或长对话恢复时，执行总控的 [改稿联动与原件交接](references/revision-impact.md)：本集后文与已写后续集一起检查，完整新版与差异先保存，确认后才使真实依赖的下游过期；不靠一句局部替换或摘要代替原件。

进入本阶段（含直接调用）先执行 [九阶段菜单与保存位置](references/stage-entry-and-paths.md)：显示本阶段中英标题，按规则展示并保存当前阶段菜单选择；所有读写先解析实际项目路径。此入口不改变本阶段的专业边界。

读取 `references/source.md` 作为方法来源。

输入仅限：`00-项目管理/artifact-registry.md` 登记的最新已确认概念锚定和角色圣经，以及 `00-项目管理/reference-memory.md` 中已经由用户确认、状态为“启用”、使用范围包含“故事创作（01-05）”且阶段适用图包含 03 的世界规则、地点、阵营或关键物件方法。没有适用参考时完全按原流程执行，不得主动检索。

## 适用性判断与强制规范

1. **判断标准一句话**：**这条规则会不会改变人物的选择？** 不会，就不用写。普通现实题材、家庭片、都市情感片在确认没有影响人物选择的特殊规则后跳过，并记录实际理由；不能仅凭题材名自动跳过。现实题材中的家族制度、职业限制或地方规约若改变选择，也应按需要记录。已跳过不生成空白确认稿，严禁硬造负担。
2. **八块中文结构**：需要建立世界观时（科幻、奇幻、超能力、架空历史、门派/帝国/法外之地等特殊规则），按 `references/source.md` 的八块结构填写，不需要的块写“本片不涉及”并说明原因；每条规则必须写清使用限制与代价，伏笔物件表必须与 `01` 对齐，信息差表必须标明「谁以为知道但其实错了」。
3. **设定视觉化（禁对白倾倒）**：严禁通过角色台词解释设定（「你也知道，我们的法术靠血换」），必须转化为动作、画面物件与后果。
4. **输出、版本卡与知识库应用单**：创作输出仅限 `03-世界观/worldbuilding-vNNN.md`（云文件夹单目录模式对应 `03-世界观-vNNN.md`），末尾附**【版本卡 · 03 世界观】**。若加载了参考方法，同时创建 `00-项目管理/参考应用单/03-worldbuilding-vNNN.md`，逐条写明实际落到哪条世界规则、地点、阵营、物件或限制；无法落地的写明原因。应用单只做审计，不混入世界观正文。每次完整修改先扫描已有文件取得下一个三位版本号，保存为草稿并登记；用户确认后由总控同时确认世界观及其应用单。

项目事实和当前分支 Skill 规则高于参考方法。参考方法与概念锚定或角色圣经冲突时标记待复核，不得为了套参考改写用户世界设定。

禁止：改写已确认的大纲和角色圣经；禁止生成分场、剧本、压力测试报告、图像和视频提示词。

完成后标记“待人工确认”，附上版本卡，并停止等待确认。
