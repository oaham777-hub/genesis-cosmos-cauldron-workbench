# E｜AI STUDIO 洋子·快速出片（短剧速产方法）

E 是 01 的第五个作品入口，复用原 01–09 九阶段和同一套版本登记，不是额外 Skill、不是直接生成视频。它适合希望迅速拿到可生产的商业短剧方案与首批剧本的作者。C 保留为可充分讨论、自由定制的流媒体／类型剧路线；用户已明确选择 C 时不得偷偷改判 E。

## 启动与事实优先级

- 只在 01 编剧定位时把“选 E”“编剧快速出片”“按洋子快速出片”判为 E。用户在 09 说“快速出片拍镜头／模式”只切换 09 合作档位，绝不改动 01 定位。已有明确故事、角色、结局或平台时先继承，不要求重新填问卷。
- 只在确实缺少且会改变方案时，一次性补问发行地区或语言、目标观众、题材、付费／免费、总集数与单集目标时长；不确定的可标为“暂定”，让作者在第一版成果上修改。不得默认所有人都是国内女频、80 集或付费剧。
- 项目事实与作者已确认剧情高于类型配方。配方只提供可选择的写作方法；不替作者改主角目标、世界规则、人物关系或结局。
- 第 01 阶段先形成讲得通的完整故事主线：起因、人物想得到什么、第一次主动行动、代价、阶段性反击、局势升级、中段改变、最后如何兑现。再安排爽点和分集，不用几个钩子词冒充故事。

## 类型与发动机

1. 从作者题材中确定一种主要观看承诺：逆袭、情感关系、悬疑揭露、家庭冲突、成长或奇幻冒险；允许混搭，但说明主线和副线如何互相推动。
2. “底牌／金手指”可以是能力、身份、资源、知识差、证据、专业技能或关系网络。超自然能力必须受 03 世界规则与代价约束；现实题材不得凭空开系统。底牌首次使用要解决具体难题，同时暴露新的代价或敌意。
3. “打脸”不是群演齐喊震惊，而是有人曾做出可见的错误判断，主角通过行动或证据改变局面；反应来自人物利益，不能每集用同一场羞辱与同一套翻盘。
4. 反派按阶段施压：每个对手有资源、欲望和阶段性胜利；小目标兑现后，更高层阻力从既有因果中出现。不能靠反派集体降智维持主角厉害。
5. 情感、亲情或搭档副线改变主角的选择成本，不只是打脸间隙的装饰；每次关系推进要在后续剧情留下影响。
6. 国内／海外、男频／女频及题材标签只能提示受众预期，不能代替真实人物和文化语境；涉及地方制度、职业或文化事实时，未知即标待核实，不假装已查证市场数据。

## 全剧到单集的两层结构

- 全剧先明确开局承诺、初次兑现、扩局、中段质变、终局兑现五种任务；这是功能划分，不预设固定集数或比例。长连载可以分多个小弧，短集数可合并任务。
- 每集记录：本集人物目标、当下阻力、主动策略、实质变化、对上一集承诺的兑现、本集留给下一集的问题。集型可在反击、蓄压、身份揭示、关系变化、对手反扑、关键选择与终局兑现之间轮换；不规定“每集必须打脸”。
- 开场应尽快交出人物处境与异常，不机械规定三秒内必须羞辱或十五秒内必须危机。单集尾部可留悬念，但必须来自本集真实行动或新信息；下一集要有可见兑现，不反复骗观众“马上揭晓”。
- 免费发行只做集末留存与承诺兑现；付费发行才规划免费转付费位置和付费后兑现。付费点位置取决于实际集数与平台要求，不按固定第几集硬套。卡点不是截断一句台词代替剧情，卡前问题要值得追，卡后第一集必须解决或实质推进。
- 检查重复：连续出现相同施压、同类翻盘或换皮反派时，优先更换主角策略、损失、信息差或关系后果，而不是单纯加音效与更大排场。

## 九阶段中的唯一负责人

| 阶段 | E 的产物与边界 |
| --- | --- |
| 01 故事 | 完整可修改的全剧故事主线、类型承诺、主副引擎、重要代价、阶段性兑现、结局、付费／免费策略；保存在 `01-概念锚定/synopsis-vNNN.md`，先确认故事事实。 |
| 02 人物 | 系统从已确认 01 生成完整**文字角色圣经**，与其他定位执行同一 02 交付标准：核心人物逐人写身份与可拍外观、过去、欲望与需求、阻力与代价、主动策略、资源与限制、人物弧光、关系、可辨声线及示例对白、状态连续性，并做声音可辨测试。省去作者填表，不省略正式成果；保存 `02-角色圣经/characters-vNNN.md`，人物图片仍归 07。 |
| 03 世界观 | 现实题材只保留必要规则；奇幻、历史、科幻或特殊职业规则影响选择时补边界与代价；不能跳过实际影响剧情的规则。 |
| 04 分集与分场 | 可先规划全剧集弧，再优先把准备写成剧本的集数拆成真实逐场：场号、地点、人物、行动、冲突、变化、集尾和初步时长。分集一句话不是分场。 |
| 05 专业剧本 | 优先交付前三集的完整剧本，后续按批继续；每集依已确认 04 写动作与准确对白，并重新估时。未写的集只标“大纲”，不得称已完成全剧本。已有完整正文时先检查和格式归一，不无谓重写。 |
| 06 压力测试 | 作者可选；按发行目标检查人物因果、兑现、重复、中段乏力和对白可演性，只报病灶，不擅改稿。 |
| 07–09 制作 | 与其他入口共用 Lira、ACTING 和 CINEDANCE；E 不跳过图像资产、表演、镜头清单确认和模型提示词质检。 |

## 交互与回退

- 少问不等于暗中确认。每道先保存草稿，作者确认后才成为下游权威；01 与 02 是否合并一次确认以总控正式规则为准，未定前分别确认。
- 04 发现结构问题需改 01 或 02：先写问题与差异，生成新草稿；作者确认后仅更新受影响阶段。05 不得为了爽点自行移动已确认场次。
- 新 01／02／04／05 确认版使真实依赖旧版的下游失效；旧稿保留。用户可退回任何阶段，但不能把旧提示词当作新版镜头的可用产物。
- 06 只审已写成正式剧本的首批集；可对照全剧故事主线检查方向，不能声称审过未写成剧本的集。先记报告和作者授权，再按根因回到 01／02／03／04／05：角色事实有错才改 02，单场表演不足只改 05。新草稿不影响旧确认稿；新 05 确认后将依赖旧剧本文件的制作资料和 09 镜头／提示词先标过期，保留 09 合作档位。全批剧本共用一份文件时，不得凭感觉宣称某场完全未受影响；先做新旧逐场对照，确认未变场次后可在新依据下复用其内容，是否重测06由作者选择；默认按修订路线继续制作，旧报告不冒称已审新版。
