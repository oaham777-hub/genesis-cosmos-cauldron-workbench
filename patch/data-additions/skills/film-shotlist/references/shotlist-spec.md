# 镜表规格 v1（不丢信息版）

本文件定义 `05_shots/epNN-shotlist.md` 的列、两行制、状态机与自检。设计依据：乾坤鼎 2026-10-11 的"一件一表、属性升级为列"整合记录，以及"制表不为完整性负责，只为一线性负责"的原则。

## 一、为什么是两行制

列太多会读不动，删列会丢信息，所以**不删列，改成每镜两行**：第 1 行放"决定怎么拍"，第 2 行放"决定拍出来长什么样"。两行同镜号，靠镜号对齐，不靠空行。

## 二、列定义（第 1 行）

| 列 | 必填 | 取值 | 说明 |
|---|---|---|---|
| 镜号 | 是 | `S01` 起，连续 | 一位场号 + 两位镜号，如 `S03` |
| 对应条目 | 是 | 场号 + 剧本文本行号或段落关键词 | 让下游能回到剧本原文 |
| 时长 | 是 | 秒，一位小数 | 粗分镜可写区间 `3–4s` |
| 景别 | 是 | 大远/远/全/中全/中/中近/近/特/大特 | 允许复合 `近→特` 表示推 |
| 机位与轴线 | 是 | 主机位角度 + 轴线关系 | 例：`平视/轴线内侧/过肩` |
| 镜头语言 | 是 | 五项：机位意图 / 运镜节奏 / 构图策略 / 视点归属 / 景别理由 | **缺一不得下传** |
| 首帧与参考绑定 | 否 | 资产编号，多个用 `+` | 只写编号，例：`asset-03+asset-11` |
| 状态 | 是 | 已定 / 待定 / 待确认 / 废弃（+理由） | 禁止空白 |

## 三、列定义（第 2 行，同镜号）

| 列 | 必填 | 内容 |
|---|---|---|
| 摄影 | 建议 | 焦段、画幅、白平衡、承托方式（手持/轨道/稳器）、焦点控制 |
| 画面 | 建议 | 主体占位、前后景、色彩逻辑、画面锚点 |
| 光影 | 建议 | 主光方向、光质软硬、色温、光比、补光与实用光 |

第 2 行可写 `—`（表示沿用上一镜），但**同一场里不允许连续三镜都用 `—`**。

## 四、模板

```
| 镜号 | 对应条目 | 时长 | 景别 | 机位与轴线 | 镜头语言 | 首帧与参考绑定 | 状态 |
| S01 | 场 3 · "她推开门" | 4.0 | 全 | 平视/轴线内侧/正面 | 交代空间受压/静态/居中对称/客观/先给距离 | asset-11 | 已定 |
| ↳ | 摄影：24mm 2.39:1 3200K 轨道推；画面：人在门框内占 1/3，前景门缝；光影：侧逆光 + 门缝实用光 | | | | | | |
| S02 | 场 3 · 对白第一句 | 3.5 | 近 | 略仰/轴线内侧/过肩 | 压迫感/微推/三分左置/她视点/靠最近距离 | asset-03+asset-11 | 已定 |
| ↳ | 摄影：85mm 2.39:1 3200K 手持；画面：肩部做前框，眼神落点右上；光影：主光已定，补 1/4 冷 | | | | | | |
```

**镜号列写 `↳` 表示续行**，解析时向上找最近一个 `Sxx`。

## 五、状态机

- `已定`：定了就不改，除非被点名。
- `待定`：写不出，等条件（例：`待定（等场景图再定机位）`）。
- `待确认`：已写但没被作者确认。
- `废弃`：保留行、标理由（`废弃（与 S05 重复）`），下游跳过。

只能四种，**必须带理由（除 `已定`）**。空白 = 造假确定性，是最严重的错误。

## 六、粗分镜 / 锁定版

| 版本 | 允许状态 | 允许空列 | 用途 |
|---|---|---|---|
| 粗分镜 | 大量 `待定` | 第 2 行可整行 `—` | 讨论、试写、估时长 |
| 锁定版 | 只剩 `已定` / `废弃` | 第 1 行 8 列必须齐 | 进入 09 编译的唯一版本 |

## 七、自检清单（搭造化鼎规则用）

1. 8 列齐全，表头未改。
2. 镜号连续，`↳` 续行都能向上找到主行。
3. 状态列无空白；`待定`/`待确认`/`废弃` 都带理由。
4. 镜头语言五项写全（机位意图 / 运镜节奏 / 构图策略 / 视点归属 / 景别理由）。
5. 参考绑定只含资产编号，格式 `asset-NN`，多值用 `+`。
6. 摄影行未出现模型采样参数（seed / steps / sampler / cfg）。
7. 同一场连续三镜不应同为 `—`。
8. 镜表主行数 = 下游提示词份数。

## 八、信息不丢的三层

1. **镜表（本文件定义）**：必须一致的东西——镜号、时长、景别、机位、绑定、状态。
2. **镜卡**：意图的完整理由、备选方案、摄影笔记、表演提示；一镜一文件，按需创建。
3. **资产库**：外观描述、参考图、采用状态；镜表只引用编号，不复制描述。

三层都有名字，信息只是搬家，不是丢弃。
