# 曝光与运动组合表（L4 · reference）

> 用途：给第 3 维「摄影参数」与第 4 维「镜头语言」提供**可直接抄用的组合矩阵**与**互斥判据**，让参数能反推画面结果（雨是线还是钉、暗部是厚还是脏），而不是堆数字。
> 上位规范：`specs/cinematography.md`（三要素 / 成像参数 / 承托与运动 / 焦点控制）——**本表不另立结构，只在其内给出可取组合**。
> 关联：`references/shot-language-system.md`（景别 / 焦段 / 机位 / 运镜 / 构图五要素与频率上限）、`references/control-image.md`（控制图只管几何时序）。
> **来源与许可**：**乾坤鼎自写件**。依据为本库既有材料——`specs/cinematography.md`、`references/shot-language-system.md`、`_incoming/manju-laoli-skill-main/.../references/camera-specs-15rules.md`（升格禁令与 Time Ramp 的原始实测依据）、`imports/seedance-2.0-main` 与 `imports/director-studio` 的摄影词表；另含**摄影专业通行做法**（180° 快门角、等效快门换算、ND 与景深联动）。**无外部许可依赖**。
> **阶段声明**：本表在生成语境下作为**提示词参数**使用，不是对真实摄影机物理设定的声明；其唯一价值是**可反推画面结果**。写了参数却推不出结果 → 判 `[数字堆砌]`。

## 一、快门与运动模糊：取景表

基准：24fps 用 **180° 快门角 = 1/48 秒**，即「标准电影运动模糊」。快门越快，运动越被凝固、越显电子与紧张；越慢越糊，越显流动与失重。

| 帧率 | 快门角 | 快门速度 | 画面结果（反向选参的依据） |
|---|---|---|---|
| 24 | 180° | 1/48 | 标准电影运动模糊；**本表基准档**，对白与常规行走默认 |
| 24 | 90° | 1/96 | 偏紧偏锐；打斗与急停的「硬度」来源，水花与雨丝开始成形 |
| 24 | 45° | 1/192 | 近乎凝固；雨成钉、汗成珠、碎屑可数；用多显电子感 |
| 24 | ≤90° 配慢速平移 | 1/24 | 拖尾与糊动；失重、眩晕、回忆渗入（**全片限用，须写理由**） |
| 48/60 | 180° | 1/96 / 1/120 | 平滑运动，观感略异于电影；用于需要顺滑的机械与运动镜头 |
| 60/120 | 180°-360° | 1/120 / 1/250 | 升格素材供后期极限慢动作；**本项目默认禁用**，仅第四节授权场景 |

## 二、快门选档判据（五条）

1. **主体相对速度越高 → 快门越慢一点**（保留运动模糊以传递速度）；速度要写成「弧线」而不是「定格」。
2. **主体几乎静止（坐着说话）→ 快门回 180°**；此时用快快门，人脸忽动一帧会显得「跳」。
3. **要读出小细节（指节发力 / 剑尖震颤 / 雨珠）→ 用 45°-90° 保细节**，同时把动作幅度收小，否则会碎。
4. **一镜内不允许变频**（同一帧率下）；要变就拆镜，在相邻镜之间用剪辑换档。
5. **低照度下既要浅景深又要慢快门 → 走 ND，不升 ISO**；ISO 上限见第三节。

## 三、光圈、ISO 与互斥判据

| 项 | 判据 |
|---|---|
| **光圈场景判定** | 主体越需要被隔离（特写 / 关键道具 / 面孔）→ 光圈越大；越需要交代环境与调度（全景 / 群像）→ 光圈越小。浅景深**必须同时写清焦点落点**，否则判 `[无焦点]` |
| **ISO 决策树** | 先决定「是否允许颗粒」，再决定 ISO。ISO 800 以下不写噪点；ISO 1600-3200 写「均匀细颗粒、暗部保留层次」；ISO 3200 以上必须写明「颗粒成为质感」并同时收快门档。**禁止「高 ISO + 干净无噪 + 油亮暗部」三重矛盾** |
| **ND 用法** | 白天要浅景深又不想升快门 → 加 ND，保住 1/48 与目标光圈。ND 只降进光，**不改变运动渲染** |
| **互斥一（大三元）** | **广角大景深 + 大光圈 + 夜雨手持** 三者不可同时成立；必须舍一个：改景别、改承托、或改光比 |
| **互斥二** | **快快门 + 强手持 + 近景人脸** 会放大每一帧的抖动；要快快门就用稳定承托，要手持就把快门放回 180° |
| **互斥三** | **慢快门与短时高密度动作互为敌人**；动作密度高时快门不许低于 180° |

## 四、运动组合与升格禁令（本项目特有）

承托与运动的组合遵循 `references/shot-language-system.md` 第四节（四级运镜、频率上限、连续三镜不得同质）。本节只补三条**与曝光绑定**的关系：

1. **手持 + 跟拍** → 快门回 180°，并写明**呼吸感幅度**与「是否允许轻微失焦」。
2. **稳定器 + 长位移** → 快门可收到 90° 让画面「硬」一点，同时把 ISO 压下去；不要用快快门去掩盖承托不足。
3. **摇臂 / 升降 + 空间揭示** → 快门不参与叙事，用 180° 把表达权交给运动本身。

### 升格禁令与三处例外

**默认禁用升格慢镜**（依据 `camera-specs-15rules.md`：2026-09-02 实测破坏节奏）；蓄力段只用 1-2 个紧凑镜头带过。允许的例外仅三处：

| # | 例外 | 写法约束 |
|---|---|---|
| 1 | 雨滴 / 碎屑的物理特写 | 只用于单点物理美感，不得用于叙事段落 |
| 2 | 受击瞬间的 Time Ramp | **仅命中帧前后 0.2 秒**，禁整段升格 |
| 3 | 片尾定格前后的回头一瞥 | 全片限一次 |

例外必须写明**用途与时长**，并登记进 `05_shots/<场次ID>/scene-registry.md`；未写理由的升格按违规处理。

## 五、组合矩阵（12 组，可直接抄进镜头表）

> 写法：`快门 · 光圈 · ISO ·（ND）· 焦段 · 白平衡 · 承托 + 运动 + 速度`。焦段按 `shot-language-system.md` 与景别绑定写。

| # | 场景 / 意图 | 曝光与运动组合 | 画面结果 |
|---|---|---|---|
| 1 | 夜雨骑手（开场） | 1/48 · f/2.0 · ISO 1600 · 35mm · 4300K · 手持跟拍中速 | 湿地面有反光、雨成线不成钉；主体与霓虹分离；呼吸感传递不稳定 |
| 2 | 对话中景 | 1/48 · f/2.8 · ISO 400 · 50mm · 5600K · 三脚架固定 | 运动模糊标准、环境可读，脸与手同时实焦 |
| 3 | 紧张特写 | 1/96 · f/2.0 · ISO 800 · 85mm · 5600K · 手持轻微 | 偏锐偏硬；瞳孔与睫毛细节立住，抖动被快门压住 |
| 4 | 手部 / 指节发力 | 1/192 · f/2.0 · ISO 800 · 85mm 或微距 · 稳定器 | 细节凝固、汗珠可数；须把动作幅度收小，否则显碎 |
| 5 | 白天街头跟拍 | 1/48 · f/2.0 · ISO 100 · **ND 0.9（3 档）** · 50mm · 5600K · 稳定器低速位移 | 浅景深 + 标准模糊；ND 保住快门与光圈，运动是流线而非定格 |
| 6 | 雨夜追逐 | 1/48 · f/1.8 · ISO 3200 · 24mm · 4300K · 手持跟拍高速 · 焦点锁定奔跑者 | 低饱和冷灰蓝、暗部厚重；环境虚成色块，速度靠模糊传递 |
| 7 | 室内压迫对话 | 1/48 · f/1.4 · ISO 1600 · 50mm · 3200K · 三脚架固定 + 第 3 秒跟焦转移（1 秒） | 背景化成色光；压迫来自景深与焦点转移，不来自运镜 |
| 8 | 空间揭示 | 1/48 · f/5.6 · ISO 400 · 24mm · 5600K · 摇臂升降缓速 | 全实焦、暗部干净；运动本身承担叙事，不用模糊 |
| 9 | 群像同框 | 1/48 · f/4 · ISO 400 · 35mm · 5600K · 滑轨横移中速 | 多人同时可读、前后景成立；景别有变化而非同质 |
| 10 | 打斗命中帧 | 1/96 · f/2.8 · ISO 800 · 35mm · 5600K · 手持 + 命中瞬间 1-2 帧震动脉冲 | 硬、脆、短促；径向模糊方向与位移严格匹配，禁全屏均匀模糊 |
| 11 | 受击瞬间 | 1/250（**仅命中帧前后 0.2 秒**）· f/2.8 · ISO 800 · 35mm · 手持 + 瞬时焦点转移 | 命中帧清晰、前后拖出极短变速；禁整段升格 |
| 12 | 回忆 / 失重插入 | 1/24 · f/2.8 · ISO 400 · 50mm · 4300K · 稳定器慢速平移 | 拖尾与糊动；**全片限量**、必须写理由 |

**换档纪律**：同场内优先只换一个档位（例如只把快门从 180° 收到 90°），换两个以上必须说明是复合设计；连续三镜不得使用同一组参数（否则判同质）。

## 六、自检（每镜写完后过一遍）

1. 三要素能否**反推出画面结果**（雨成线还是成钉？暗部是厚还是脏？）→ 推不出即 `[数字堆砌]`。
2. 光圈—景深—**焦点落点**是否在同一句里自洽 → 否则 `[无焦点]`。
3. 承托是否由运动速度买单（手持有没有被快快门放大抖动）。
4. 该镜档位与相邻镜是否失去对比，或连续三镜同质。
5. 是否出现被禁止的升格慢镜而未写理由与时长。
6. 参数组合是否与第 7 维色彩、第 8 维光影自洽（**L4 只负责写得可核，自洽结论在 L6 编译时复核**）。
7. 高 ISO 与「干净无噪」是否同时出现（三重矛盾）。
