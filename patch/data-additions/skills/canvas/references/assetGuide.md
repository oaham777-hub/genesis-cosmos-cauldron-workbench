# 资产图规范

写**资产提示词**（角色、场景、道具）之前读这份。写**视频提示词**另见 [片段制作指南](productionGuide.md)。

资产不是"好看的图"，是后面几十个镜头要反复引用的素材。判定标准只有一条：**把它丢进任何一个镜头里，观众认得出是同一个人、同一个地方、同一件东西。**

## 1. 先列清单，再出图

从本次已确认的剧本里点名：出现过的角色、去过的场景、被特写或被使用的道具。清单没核对完不要开始出图——缺一个角色，后面所有带他的镜头都要重做。

清单写成三组，一一对应后续命名：

- 角色：`角色名`（群演按"人群-集市"这类描述命名，不做单独资产）
- 场景：`地点-时间段`（同一地点的白天/夜晚是两份资产）
- 道具：`道具名`（只有被特写、被拿起、被反复出现的才做）

## 2. 角色资产：四张，缺一不可

每个角色至少四张，**不要省成一张通用剧情图**：

| 图 | 用途 | 要求 |
|---|---|---|
| 面部特写 | 身份锚点，多参生成时最先上传 | 正脸、平光、无表情或极中性表情、能看清眉眼神态 |
| 正视图 | 身形与服装 | 全身、平视、双臂自然下垂 |
| 侧视图 | 骨相与体态 | 90 度侧面、同一站姿 |
| 背视图 | 发型与背面服装 | 180 度背面、同一站姿 |

四张必须**同一人、同一套服装、同一光线、同一背景**。背景用纯色或极简影棚，不要场景化。

禁止出现在角色资产里：剧情动作、说话、多人同框、手部大特写（手容易崩）、文字水印、强烈风格化滤镜（会把风格锁死在资产里）。

## 3. 场景资产：三档

- **全景**：交代空间结构、出入口、地面材质
- **中景**：有人物尺度参照（可放一个背影或远景小人），说明"人站在这里多高"
- **细节**：一份材质或光源特写（木纹、砖墙、灯具、窗外光）

同一场景的全景与细节必须同光源方向，否则后续接戏会穿。

## 4. 道具资产：两角度

单件居中、中性背景、正面 + 侧面各一张。有文字、logo、刻字的道具，额外加一张文字特写——这类细节在视频里最容易糊。

## 5. 一致性靠复用描述，不靠运气

- 每个角色维护一段**固定的外观描述**（年龄段、脸型、发型发色、肤色、体型、服装款式与颜色、标志性配件），每次出图原样粘贴，不要每次改写措辞。
- 同一角色改外观 = 新版本资产，旧图保留但标记停用，不要让两个版本同时被镜头引用。
- 命名统一 `角色名-视图`、`地点-时间段-档位`、`道具名-角度`，中文可以，不要空格。

## 6. 资产提示词的结构

```
主体 → 外观（固定描述） → 服装 → 构图与视角 → 背景 → 光线 → 画质
```

只写"这张图里有什么"，不写镜头运动、不写剧情、不写台词。视频提示词才管时间。

## 7. 交付前核对

- 四张角色图是不是同一个人（对比脸型、发型、服装细节）
- 场景图的光源方向是否一致
- 文件名是否与清单一致、能否被后续片段直接引用
- 有没有把剧情动作混进资产图
