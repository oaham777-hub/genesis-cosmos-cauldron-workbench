# 片段制作指南

写**视频提示词**之前读这份。资产本身怎么做见 [资产图规范](assetGuide.md)。

## 1. 一个片段 = 一份提示词 = 一个视频节点

不要一个镜头一个节点。同一场戏里连续的几个镜头，写进同一份提示词，按时间推进展开；节点数应该等于**片段数**，而不是镜头数。镜头的切换在提示词内部用时间点表达。

拆片段看戏剧节拍：一次情绪转折、一次空间转移、一次对话回合。一个片段 2–6 个镜头为宜，超过就该拆，否则模型会自己"跳剪"，你控制不住。

单片段的时长上限由所选模型决定，**触发生成前先核对当前模型能力**，不要按记忆里的数字写。

## 2. 先资产，后片段

顺序不能反：角色/场景/道具资产确认 → 再把本片段所有镜头转写成一份视频提示词 → 资产作为参考素材接进节点。剧本和分镜文本只用于规划，**不直接当图片或视频节点的输入**。

连线只承载本次真正用到的素材。把一个片段里没用到的角色图也连上，会稀释参考权重。

## 3. 参考素材的绑定

- 人物资产 → 身份参考；关键帧 → 画面参考；运动参考 → 运镜/动作来源；音色素材 → 声音。
- **上传/连线的顺序必须与提示词里编号的顺序一致**，编号错位是"人和服装串了"最常见的原因。
- 同一张图不要既当身份参考又当首帧参考——模型会两难，选一个角色并保持整个片段一致。
- 连线成功不等于绑定成功：连完要核对目标节点的实际引用顺序，再写提示词里的素材名称与用途。

## 4. 提示词结构（按时间推进写）

```
时长与画幅 → 首镜构图/站位/光线 → 时间推进的动作、摄影机、表演、对白 → 环境声与动作声 → 连续性与限制
```

- 时间推进用明确的时间点或"随后/与此同时"这类顺序词，**不要写"同上/继续/上一镜"**——片段之间不共享上下文。
- 摄影机写清机位与运动（推、拉、摇、移、跟、升降），不写"电影感"这类形容词。
- 表演写可执行的动作与表情变化，不写"悲伤"这种结论词。
- 对白原样保留，不改写、不润色、不翻译；说话人用清晰的标记区分。
- 声音分三层：对白进正文，环境声与动作声单独说，配乐单独说；没有就明说不加。

## 5. 换模型必须重写，不是替换

不同视频模型的提示词格式、首帧支持、时长与画幅约束都不同。同一份文本换个模型名就提交，是穿帮和废片的主要来源。切换模型时按该模型的结构重写一遍，并重新核对参考素材的绑定方式。

需要双版本（比如同时要两个模型的稿）时，分成两个独立成品，不要混在同一份文本里。

## 6. 连续性检查（提交前必看）

- 人物服装、发型、道具位置在同一片段内是否一致
- 光源方向是否跨镜头翻转
- 空间关系是否自洽（谁在门内、谁在门外、动作朝哪边）
- 是否有"突然出现/消失"的人和物
- 对白是否被改写、时间标记是否递增
- 参考素材顺序是否与提示词编号一致

任何一条不过，改提示词，不要靠多生成几次碰运气。

## 7. 生成与交付

生成在后台跑，开始与完成是两件事：发起后不要假设已完成，按工具返回的状态确认，完成后回到画布核对实际产出是否与提示词一致（时长、画幅、首帧、人物身份）。不一致就回到第 6 节。
