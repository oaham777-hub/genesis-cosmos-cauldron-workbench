# 第一部 · 表演导演层（源 A）

## 一、单一方向 + 各自动机（场面级唯一方向）

五柱是**逐角色**的。它们不回答「什么把这个场面凝在一起」——所以只按五柱搭出来的戏，常读成「几个各自不错的表演，只是没在同一个场面里」。五柱之上还有一层：

| 层 | 属于谁 | 例（母亲送儿子出门） |
|---|---|---|
| **场次方向** | 全场共享 | *别让告别变苦* |
| **动机（燃料）** | 每个角色各一 | *迷信——出行前流泪是不祥* / *为了他* |
| **目标（五柱之一）** | 每个角色各一 | *把他稳稳送走* |
| **战术（五柱之一）** | 每个角色各一 | *照常收拾行李，偷看几眼* |

**场次方向**通常是**不宣之于口**的默契：这一次我们要怎么过。它属于在场的所有人，**不是影片的戏剧功能**——角色从不表演主题或反转，那是**经由他们**产生的副产品。

**每条角色用各自的理由推同一个方向**——这就是**动机燃料**。同一个矢量、不同燃料，是让「表演各自成立而场面仍统一」的那一块，也是最常被跳过、一跳过就把群像压成一个音的。

**既定情境约束动机**：已经接下妥协工作的角色，不可能演出道德上的清白。动机与背景冲突时，**重推动机**，不要改背景。

### 命名事件：从结尾往回读

**先看这场戏怎么结束**，再命名它「是什么」。最后一句或最后一个节拍是钥匙，整场戏是倒着读它读出来的；**留意带双关的收尾台词**——说的是这件事、指的是另一件事。

**检验：事件必须包含场内的每一个角色**，包括沉默的和无意识的人，作为参与者或同一过程的镜像。**只要有角色站在命名的事件之外，就是事件命名错了**——一直改到他们都在里面。这是本文件最便宜的结构检查，专治「有一角色只是被摆在场上」。

### 物理动作是通道

表面的活动（地形）保持在物理动作上，每个角色**经由它、用自己的、可被镜头读到的行为**推进事件。看不见的任务必须有看得见的通道，否则模型无从渲染。

一个地形（例：例行查房），一个事件（例：求取自我宽恕），三条通道：一个通过**回忆**（闭眼下的快速眼动、一滴泪）；一个通过**把该做的做对**（指标正确、准点、重复核对）；一个通过**多照看一点**（越过清单的照护动作，看人而不是看图表）。

**给场上每个角色同一个事件的不同物理通道**——不同行为、一个事件、一个地形。这才是把表演笔记变成可生成内容的写法。

### 对比配对（双人戏的加/−结构）

双人戏更实的一种搭法：**每人各带一加一减，且与对手相反**，并指定**一条主轴**作为观众真正读到的那组对立；其他特质只是颜色。

**看似的那一面，常常是它反面结出的痂**——「漫不经心」可能是希望落了空，不是不在意。**要导的是身世，不是表面。**

## 二、五柱的可执行化（宏观层）

| 柱 | 必须回答到可拍的程度 |
|---|---|
| **目标** | 一句**动词**、指向**特定对手**：「让他认账」「求他宽限一周」「说服她我不怕」。**永不写状态**（「生气」「内疚」）——状态演不出来 |
| **障碍与代价** | 外部（对手想要反的、屋里有证人、两小时期限）或内部（自尊不许人求、自己不信自己的话）。**必须回答：拿不到会怎样？**答案要**吓到角色自己** |
| **战术** | 当下的具体手段：施压 · 讨好 · 羞辱 · 哀求 · 挑衅 · 讲价 · 威胁 · 拖延。**一个战术演一整场 = 死表演**；战术失败，活人**换战术** |
| **节拍** | 最小行动单元：想要一个东西、用一种方式追求的那一段。**每次转向必须在行为上可见**：一次停顿、一次姿态变化、一次速度变化、一次视线转移。一场好戏有 **2–4 次转向** |
| **潜台词** | 角色真正想/想要的，与他说出来的话之间的差。**潜台词不是演出来的**——当他一边说假话一边追真目标时，它自己会漏 |

### 潜台词的五个可执行标记

要写进表演资产、能被镜头读到的，只有这些：

1. **不是问题的问句**（反问、明知故问）；
2. **重复**（问同一件事——因为他不信那个答案）；
3. **突然换话题**；
4. **不合时宜的玩笑**（挡在脆弱前面的盾）；
5. **过短的回答**（「行。」「随便。」——一扇关上的门）。

> 潜台词的正向写法：写**他在追什么**与**他在说什么**，两者之间的缝就是潜台词。**不要写「他在掩饰」，要写掩饰的动作。**（与 `acting-patterns.md` 第四节「情绪名不进提示词」同一条纪律。）

# 第二部 · 听、距离与地位（对白戏的机制）

## 三、听的四个可观测标记（源 A）

对白戏的表演活在**台词之间**，不在台词上。四个标记必须写进表演资产：

1. **反应在对方台词结束之前就开始了**——活人在句子中途就懂了，脸和身体当下就答了。**台词结束才「打开开关」的脸，就是死表演。**
2. **先想后说**——回答难题之前有一处**微停**：人 visibly 在决定要说什么。**等速的即时回答读起来像背过的台词。**
3. **评估时刻**——听到消息、威胁、羞辱之后，人需要时间消化，从零点几秒到一段长停。**电影就活在这些评估的特写上**：一张脸、一处失焦的凝视、世界在游走。
4. **被对手传染**——速度、音量、能量会**回应**对方：一声吼要么被吼回去、要么被刻意的安静接住，但**必须被接住**，不能被盖过去。

### 沉默的听者也要领任务

上面四个标记只说明反应**读起来**是什么样；它们没给听者一个「在标记之间正在做什么」的事。**没有任务的听者，就是双人镜头里死脸回潮的地方。**

给听者派活：*判断他是不是当真 · 等那个缝隙 · 护住气氛 · 抓住他话里的破绽*。**每个入画的人因此都有了活的眼睛。**

## 四、距离：场面戏剧的度量（源 A / B）

距离是关系**可见的图**。**必须用米写**（与 L4 的「可测量语言」一致）：

| 区 | 距离 | 读作 |
|---|---|---|
| 亲密 | < 0.5 m | 爱或暴力；**未经允许地进入＝攻击** |
| 个人 | 0.5–1.2 m | 信任 |
| 社交 | 1.2–3.5 m | 公务、戒备 |
| 公共 | 3.5 m+ | 疏离、层级 |

- **当面 10 厘米说出的威胁，比隔着房间吼出来的更可怕。**
- 场面戏剧常常就是距离的故事：**谁靠近、谁破开、谁僵住**。
- **距离的变化就是节拍的变化**——必须写进镜头，用米制。
- 镜头远近也要对得上关系：**摄影机越近，越表示亲密、威胁、羞耻、揭露或崩溃**（与 L4 景别取值配合）。

## 五、地位：看不见的层级（源 A）

**地位是你做了什么，不是你是谁。**

| 高地位 | 低地位 |
|---|---|
| 头不动、动作慢、凝视长、答话前有停顿、占空间、随手碰别人的东西 | 小动作多、频繁自我触碰（脸、头发）、话被打断、陪笑填空、用眼睛要许可 |

**一场表演里最有意思的东西是「地位破绽」**：老板有一秒露出恐惧；下属忽然不笑了。有力的场面形状是**进场高、随后崩**，或**进场低、翻掉整个房间**。

**面具与裂缝（写作纪律，源 A）**：
- **每一个小动作都要带触发条件**——不是「他掰指节」，而是「他在闲聊时掰指节，用来假装自信」。格式：`[小动作] + [何时/为何]`。**没有触发的小动作是装饰；有触发条件的小动作才是戏剧。**
- **每个面具都要有裂缝**：至少写一条「然而，当 ×× 时，……」——支配的姿态在被拒时塌成孩子气的塌肩；严苛的自律在某个特定的人面前化开。**一个角色同时扛两条真相，是木偶与人的差别。**
- **一个软化的对象**：只给一张人/动物/物的脸，让它真的软下来。**只给一个。**
- **步态要命名**：「巡场步」「孔雀步」「攻城步」——先起个绰号锚住生物力学，再拆开：重心、步幅、躯干与手臂做什么、头做什么。
- **门面与裂缝都不进衣着、不进镜头、不进颜色**（衣着在场景/造型块，镜头在 L4）。

## 六、手上的事（business）与被截断的动作（源 A）

角色几乎总得有一件**正在做的事**。他们不「进行一次对话」——他们修发动机、数钱、做饭、擦杯子，**在事情上面说话**。

- **手上的事杀掉假戏感**（手忙着真的东西）、**造出节奏**（停顿被动作填满）、**生出潜台词**（怎么数钱，比说什么都多）。
- **被截断的动作律**：最强的重音是角色**停下手上的事**。如果他一直在切面包，在某个词上停住了——那个词就变成了事件。**用「停」当标点。**

# 第三部 · 对白节奏与转向（源 C + 源 B）

## 七、对白戏四条硬规矩

1. **避免长时间的中性说话头**——没有调度、没有反应的对话特写是对白戏的头号死法。
2. **每句台词要么进攻、要么防守、要么揭示、要么隐瞒、要么打破**。做不到其中之五句之一，这句话就不该在戏里。（这是 L2 台词层的病，但**表演层可以把它显性化**：写资产时给每句台词标上这五类之一。）
3. **情绪向量六种**——写好一场对白戏的「力」的方向：**压抑 · 爆发 · 诱惑 · 哀求 · 威胁 · 崩溃**。每场只许一个主向量，节拍转向时可以换。
4. **加沉默与反应节拍**，只要它能锐化权力关系。**短剧要与压缩**：情绪过渡压到每个节拍都能快速读懂。

## 八、声音的口语真相（源 A）

- **节奏写在文本里**——精确交付；快 ≠ 糊。
- **抢话是常态**（台词踩着别人尾巴进来），但**关键词必须干净**；需要抢话时**明确标出重叠区间**。
- **音量对比：最可怕的东西是最小声说出来的。** 喊是弱者的通货；掌控场面的人压低音量，所有人向他倾过去。
- **停顿是事件，不是洞**：一次停顿只有在里面有事情发生时才合法——一次评估、一个决定、一次拒绝回答。
- **真实口语有杂物**：打断、听了一半的词、重复、没说完的句子。**结构过于完美的句子会杀掉街面的真实。**
- **收尾**：短剧/动作段以高潮收尾，不设平息帧（与 L4 的节奏律一致）。

## 九、零一句多余的话：场面必须有人输

> **每场戏都是某个人的失败。如果没有人输，那就没有戏。**

写作时用这条自查：这场戏结束时，**谁失去了什么**？写不出，就是场面还没成立。

# 第四部 · 简报格式、强度标度与 QA

## 十、表演简报（10 项，源 B）

每个说话或表演的主体，在生成前先写一份**能塞进提示词或交接单**的简报：

1. **介质与约束**：影视级生成 / 动画 / 广告 / 配音本地化 / 竖屏 UGC / 纯声音；
2. **选角读法**：年龄感、气场、声音质地、身体能量、**以及不可模仿谁**；
3. **既定情境**：在哪、刚刚发生了什么、他以为在跟谁说话、正在承受什么压力；
4. **目标**：这个节拍里他想从观众或对手那里得到什么；
5. **障碍**：什么让目标变难；
6. **动作动词**：安抚 · 挑战 · 诱惑 · 转移 · 坦白 · 教 · 邀请 · 警告；
7. **节拍转向**：新信息或阻力改变战术的那一刻；
8. **可见行为**：姿态、视线、手、面部肌肉、呼吸、静止、移动路径、距离与身体接触边界；
9. **声音行为**：语速、音域、音量、停顿、重音词、呼吸、笑声或迟疑；
10. **连续性与权利**：眼睛/手/身体/道具/情绪/声音的进出状态；同意与肖像范围（见第十四节）。

> **总控原则（源 B）**：**先写动作，再写情绪。**「试图赢回她的信任」通常比「很悲伤」产出更连贯的行为。**每个节拍只给一个主导目标、一次可见调整。**

## 十一、情绪强度 0–5 标度（源 B）

先定动作与目标，**再**命名底层情绪并标注**屏幕强度**：

| 级 | 读作 |
|---|---|
| 0 | 中性的任务专注 |
| 1 | 痕迹级；主要靠眼神、呼吸或时机读出来 |
| 2 | 自然的职业表达 |
| 3 | 明确的戏剧/社交可读 |
| 4 | 拉高的类型化或动画表达 |
| 5 | 漫画、惊慌、闹剧式的夸张 |

- **商业/口播/短剧多数落在 1–3；类型片、动画、喜剧与社会化钩子可到 3–5。** 短视频前 3 秒可临时上 4，随后回到 2–3。
- **允许并主动使用矛盾**：「声音保持职业，脸上露出担心」——避免全通道同一种情绪，也避免把「既大笑又咬牙」这类物理不成立的组合塞进同一个节拍。
- 面部优先用**可观测线索**：眉（松开 / 微蹙 / 内侧上扬 / 怀疑下压）、眼（看镜头 / 追踪对手 / 失焦 / 快速一瞥 / 眨眼变慢）、嘴（闭口笑 / 忍住笑 / 抿唇 / 下颌松开 / 半声笑）、头（不动 / 微点 / 偏 / 后缩 / 前倾 / 转开）。
- **不要堆**面部线索：一个节拍里塞五种表情，除非那个矛盾是**有意且物理成立**的。

## 十二、调度、手势与视线（源 B）

- **对白**：为每个角色写明**视线目标**，以及他是**回避 / 挑战 / 寻求 / 切断**。
- **影视场面**：围绕权力、回避、吸引、秘密或发现来调度。**距离与静止常常比不停移动更有表达力。**
- **手势每条都要有动词**：揭示 · 停住 · 丈量 · 保护 · 计数 · 邀请 · 打发。
- **手势尺度匹配画框**：特写用微观手势；全景才用全身动作。**不要让手在特写里乱动。**
- **视线连续性**：多镜场面必须记录**每个镜头起止时每个人在看谁/什么**。在生成里，**视线不一致常是连续性问题，而不只是脸的问题**——登记进 `05_shots/<场次ID>/scene-registry.md`。

## 十三、排练与迭代（源 B）

**排练五步**（在昂贵定稿之前）：

1. **读本**：写或生成两条不同**动作**的读法（不是两种情绪）；
2. **姿态排练**：先要关键姿势/静帧，检查剪影、视线、手的位置、表情强度；
3. **节拍排练**：只生成「节拍转向」那一小段；
4. **连续性排练**：用同一份起止状态测相邻镜；
5. **定稿表演**：**只有在表演读法成立之后**才加制作细节。

**迭代笔记要具体**（四种可引用格式）：

- 「笑从 3 降到 1；暖意留在眼里，不要露牙。」
- 「在反对意见期间保持视线，说完否认之后再低头。」
- 「只在论点那句做一次手势；到情感坦白时手停住。」
- 「这句对嘴的闭唇太快——在最后一个词前加 200–400 毫秒停顿，或换一条更慢的配音。」

## 十四、同意、肖像与声纹（源 B，乾坤鼎加严）

生成或导演一个合成人**之前**，先判定「这个人是谁」：虚构且不可辨识 / 授权素材头像 / 经同意的自定义形象 / 公众人物、员工、客户、网红、演员、已故者 / 对真实声音或样貌的**模仿**。

**自定义或可辨识形象/声音，必须取得书面范围**：

1. 谁给的同意，他是否有权授予；
2. 允许的媒体、脚本类型、地区、期限、平台与剪辑；
3. 声音/形象是否可用于训练模型、生成新台词或后续复用；
4. 报酬、撤回、存储、独家与删除条款；
5. 合成内容的披露与来源计划。

**同意缺失或有歧义时**：改为虚构/不可辨识的表演者、授权素材头像，或真人录制表演。**意图是「可辨识」时，绝不制作「听起来像/看起来像」的替身**（与 L3 `references/high-risk-assets.md` 的真人向加严项一致）。

# 第五部 · 质量门

## 十五、坏表演对照表（15 条，源 A）

认得症状，直接用提示词级修法。

| # | 症状 | 长什么样 | 提示词级修法 |
|---|---|---|---|
| 1 | 指示（挤表情） | 脸在「描绘」情绪：挑起的眉、怪相 | 把脸从任务里拿开；写目标，给手找活干 |
| 2 | 演结果 | 第一秒就在演这场戏的结局 | 只写角色**此刻知道**的事 |
| 3 | 等提示 | 对手说话时脸是空的 | 写「反应在对手台词中途开始」 |
| 4 | 单战术 | 整场一个颜色（全在吼/全在委屈） | 标节拍；每个节拍一个新战术动词 |
| 5 | 手势图解 | 手势重复词义（说「大」就张开手臂） | 手势要么先于念头、要么与话矛盾、要么没有 |
| 6 | 无来由的情绪 | 没铺垫、没触发的眼泪或暴怒 | 搭阶梯：克制 → 断裂；情绪必须付出代价 |
| 7 | 身体与身世不符 | 打手的姿态像舞者 | 设定身体档案：重心、速度、磨损 |
| 8 | 台词太干净 | 街头角色说书面长句 | 给台词加杂物：打断、断尾、重复 |
| 9 | 威胁预告 | 动手前先「阴沉」停顿、眯眼、慢转身 | 威胁是日常的；暴力**没有预告** |
| 10 | 群像同步 | 所有人同一瞬间同一反应 | 反应**成波**错开，强度各不相同 |
| 11 | 死停顿 | 静默里什么都没发生 | 用评估或手上事填满，否则剪掉 |
| 12 | 情绪复位 | 强烈事件后立刻「恢复」 | 状态有惯性；余波带进下一个节拍 |
| 13 | 评论角色 | 表演在向观众眨眼（喜剧尤其） | 完全相信情境；喜剧要**正着演** |
| 14 | 特写过载 | 特写上还在大力做表情 | **镜头越紧，动作越少**：只留眼睛与念头 |
| 15 | 死鱼眼 | 眼神冻结、不眨、不扫视、玻璃感 | 完整执行第十六节——**它从来不是可选项** |

## 十六、眼神即任务（源 A，本库原为零命中）

**死鱼眼是 AI 表演的第一号破绽。**

- **微扫视与注视目标**：视线持续移动——漂开、想事情时闪走、扫到一个细节再回来。**永不冻结。**
- **真实的眨眼率与质量**：受压力时快而密的眨眼；掌控时缓慢平静的眼睑；解离的一瞬是「眨一下然后失焦」。
- **活的反射光**：眼睛要读起来是湿的、有光的。但**反射光是「渲染」属性，不是药**——**死鱼眼不是靠灯光技巧治好的，是靠给眼睛派任务治好的。** 玻璃般的凝视配上漂亮的反射光，仍然是玻璃般的凝视。把眼神工作写成**指向对手的有目的行动**：*检查对方眼里有没有一丝信任 · 每说完一点就看他有没有接住 · 偷看一眼在被抓到之前收回来 · 丈量他，把自己感到的和他表现出来的做对比。*
- **克制的静止是「选择」，不是「死」**：要狼一般的近乎不眨眼，就让眨眼**稀少、缓慢、是决定**，并且视线仍在缓慢移动。
- **眼睛先动、头后动**：视线比转头早一点点到达目标，**念头在话之前就被读到**。
- **眼神随节拍而变**：眨眼率、注视稳定度、反射光的暖度都在节拍转向时改变。

## 十七、三通道 QA（源 B）

**有声看**：

- 他有没有在追一个清晰的目标？
- 声音是否匹配脸与身体的能量？
- 节拍转向**听得到也看得到**吗？
- 停顿像思考，还是像延迟？
- 口型的起闭是否能接受？

**无声看**：

- 能不能只从画面读**关系、注意力目标与压力**？
- 视线、姿态、手是否都有动机？
- 表情强度是否匹配题材与品牌？
- 有没有不自然的循环、冻结的眨眼、手部瑕疵、随机点头？

**纯声听**：

- 这条读法有没有**听者、战术与弧线**？
- 关键词有没有重音，而**不油不戏剧**？
- 语速是否匹配平台、信息密度与字幕？

**连续性**：起止情绪、身体朝向、视线、道具状态、服装、声音音色是否与相邻镜一致；角色参考/形象/声音是否在交接单里标明；同意与来源说明是否随资产走。

## 十八、口型 QA 六项（源 B + 本库 D1/D2 接口）

1. 口型**只在精确台词期间**运动——与 `D1/D2` 发声窗口严格对齐；
2. **起闭唇**：开口的起始与结尾的闭唇是否干净；
3. **双唇音**（b/p/m）是否闭合；
4. **摩擦音**（f/v）是否可见；
5. **下颌节奏**是否与听感相符；
6. **尾拍**：最后一个字之后嘴唇静止，**保留静默尾拍**（给表演与剪辑落地的时间）。

不匹配时的**最小修复顺序**：**先修音频的时机或句长，再去过度指挥脸**。

## 十九、修理最小失效层（源 B）

对白戏出问题时，按**由小到大**的顺序修，先修最小的那一层：

```text
脚本意图 → 声音读法 → 面部表情 → 身体动作 → 镜头 → 剪辑 → 生成设置
```

**不要跳到最后一层去改生成参数**——那通常是最贵、最不精准的一刀。

## 二十、表演评分 0–5（源 A）

| 分 | 读作 |
|---|---|
| 0 | 人偶：台词交了，行为没有 |
| 1 | 朗诵者：台词「有表情」，情绪是指示出来的，身体在图解 |
| 2 | 勤勉：能猜出目标，但只有一个战术、反应迟到、停顿是空的 |
| 3 | 匠人：目标与节拍在，会听对手，身体说得通。缺：潜台词、意外的战术、状态的惯性 |
| 4 | 活着：连续的行为、对比的战术、潜台词与台词分叉、地位写在身体里、反应先于台词、至少一个「意外但真实」的选择 |
| 5 | 磁石：4 的全部，加**悖论**——**「两条真相」律**：第 5 级时角色永远同时扛两条真相（一边帮一边恨；一边道歉一边辩护；一边爱一边已经离开）。**一条干净、没有矛盾的情绪，在特写里读起来是合成的。**

**每个英雄镜都瞄 4 分以上。** 自查在 2 分或以下的段落，**发出去之前重写**。

## 二十一、发前自检（对白戏专项）

1. 场上每个入画的人是否都写了**指向对手的目标动词**？
2. 障碍与代价是否成立、失败代价是否真实？
3. 是否有 **2–4 次节拍转向**，且每次在行为上可见？
4. 反应是否**先于对方台词结束**就开始？是否写了评估时刻？
5. 每个角色是否都有**手上的事**？是否刻意用过**被截断的动作**当标点？
6. 距离是否**变化**、变化是否有动机、是否**用米写**？
7. 地位是否写在身体里，而不只在台词里？
8. 小动作是否都带**触发条件**？面具是否有**裂缝**（「然而，当 ×× 时…」）？
9. 眼神是否写清：扫视、眨眼质量、反射光、眼睛先于念头？
10. 说台词的人是否**逐字台词 + 单一发声窗口**？不说的人是否明确**嘴唇静止**？
11. **强度标度**是否标注，且有矛盾设计吗？
12. 是否**避免长时间说话头**；每句台词是否属攻/守/露/藏/断之一？
13. 群像反应是否成波；**强的人静而少动，弱的人小动作多**？
14. 这场戏**谁输了什么**？写不出来就是场面没成立。
15. 自查评分：这一段的表演分，是否在 **4 分以上**？
