# 技能描述起草模板（负边界 / 触发词）

造化鼎的 R02/R03 要求 description 里有**触发条件**和**负边界**。它只认词表，
所以套话能过审、却不能让人看懂。这个模板把「写什么」固定下来，让 DeepSeek
按同一副骨架填，人只审一眼。

## 骨架（三段，一段一句）

```
<做什么>。<当…时使用>。不要用于：<不该做的事>（交给 <替代阶段>）、<…>（<…>）。
```

1. **做什么**：一动词开头的动宾短语，只说产出物，不解释价值。不超过 40 字。
2. **当…时使用**：必须出现阶段编号（如 `09 CINEDANCE`）或明确的输入条件
   （「作者至少有一场已定稿的戏」）。这一段是给路由看的。
3. **不要用于**：至少两条，**每条都要指向具体的替代阶段或去处**。
   只写「不要用于无关任务」等于没写——这正是上一轮 evolve 的套话。

## 硬性要求

- 全中文，专有名词（Seedance / MiniMax H3 / Lira）保留原文。
- 不出现「同上」「各种」「等等」这类模糊词。
- 不超过 260 字；超过就该拆技能，而不是加形容词。
- 负边界里指到的阶段编号必须真实存在（01–09）。

## 示例（已通过 R02/R03）

**09 film-cinedance**

> 把一个已确认的剧本场拆成已确认的生成镜头，保留已批准的导演计划，并写出可直接
> 生产的 Seedance 2.5 / Seedance 2.0 / MiniMax H3 提示词。当路由把阶段选为
> 09 CINEDANCE、且作者至少有一场内容已经定稿的戏时使用。不要用于：写剧本对白或
> 改剧本（那是 05 的事）、产出人物与场景的图像提示词与资产简报（07）、由一句随手
> 的想法直接出单张图（交给资产库）、重新规划故事结构与集数顺序（01 到 04）。

**05 film-screenplay**

> 把已确认的故事材料深度融合成导演可用的剧本，并按作者要求改稿。当路由把阶段选为
> 05 SCREENPLAY、作者需要台词、场次正文或完整剧本稿时使用。不要用于：还在发明或
> 重构情节（01 到 04）、把一场戏拆成镜头或写视频模型提示词（09）、为人设与场景写
> 图像提示词（07）、不改正文只做全维度体检（06）。

## 给模型的提示词（draft-desc.mjs 用的就是这段）

```
你在为 AI 影视工作台的技能写 description。技能名：{name}；它在流程里的阶段：{stage}。
它的正文摘要如下：
{body}
请按三段骨架写一条中文 description：
1) 做什么（≤40 字，动词开头，只说产出物）
2) 当…时使用（必须带阶段编号或明确输入条件）
3) 不要用于：至少两条，每条指明替代阶段编号
只输出 description 本身，不要加前缀、不要加引号、不要解释。总长 ≤260 字。
```
